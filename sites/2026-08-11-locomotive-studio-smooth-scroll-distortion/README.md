## どんなサイトか

Locomotiveは、Webサイトの「滑らかで手触りのあるスクロール体験」を語るうえで欠かせない存在です。自社の公開OSSライブラリ **Locomotive Scroll**（慣性のあるスムーススクロール＋パララックス＋ビューポート内検知をまとめたJSライブラリ）を生み出したスタジオで、そのライブラリはGitHub/npmで世界中の制作者に使われています。自社サイト自体もそのライブラリ相当の技術で作られており、Awwwardsで長年高く評価され続けています。

### 印象的だった点(推測を含む)

- **スクロールそのものを「デザイン」している**点。ページを流し見しているだけなのに、慣性のついたなめらかな動きが「上質な手触り」の第一印象を作っている。
- 作品サムネイルにカーソルを乗せると、写真が**水面に触れたように歪む**インタラクション。単なる拡大・フィルタ変化ではなく、触った場所を中心に波紋が広がる物理的なフィードバック感がある。
- カーソル自体が**要素に応じて意味を変える**(小さな点 → 大きな輪＋ラベル)ことで、「ここは押せる/見られる」という状態をテキストなしで伝えている。
- 派手な3Dではなく、**タイポグラフィと余白、動きのタイミング**だけで高級感を出している編集的(エディトリアル)なレイアウト。

## 使われている技術・ライブラリの推測

- **Locomotive Scroll**（自社製）— `data-scroll-speed`のような属性でパララックス量を指定できる、慣性スムーススクロールライブラリ。内部的にはLenisと同系統の「目標スクロール値へlerpで近づける」実装。
- **WebGL** — サムネイル画像のディスプレイスメント(歪み)効果に使用していると推測。`data-gl-image-*`のようなデータ属性で画像をテクスチャとして読み込み、シェーダーで加工する仕組みがLocomotiveのツール群に見られる。
- **Charcoal**（自社製CMS/PHPフレームワーク）— コンテンツ管理側。
- カスタムカーソル・IntersectionObserverによるテキストや画像のイン・ビューアニメーション。

## 再現デモの仕組み

`index.html`は、外部ライブラリを一切使わず**Web標準APIだけ**で、上記の表現技法を再実装した学習用デモです。

### 1. 慣性スムーススクロール(`SmoothScroll`クラス)

- 見た目のコンテンツ`#scroll-content`は`position: fixed`で画面に固定し、透明な`#scroll-spacer`だけに実際のページの高さを持たせて、ブラウザ本来のスクロール量(`window.scrollY`)を発生させます。
- `window.scrollY`を「目標値(target)」、実際に画面へ反映する値を「現在値(current)」として持ち、毎フレーム

  ```js
  current += (target - current) * ease; // ease = 0.085
  content.style.transform = `translate3d(0, ${-current}px, 0)`;
  ```

  のように**lerp(線形補間)**で近づけることで、指を止めてもすっと減速しながら止まる慣性のある動きになります。これがLocomotive Scroll / Lenisなど多くのスムーススクロールライブラリに共通する基本原理です。
- `data-speed`属性を持つ要素は、画面中央からの距離に応じて逆方向にずらすことで簡易パララックスを実現しています(値が大きいほど遅れて/先行して動く)。

### 2. WebGLによるマウス追従リップル(水面歪み)画像エフェクト(`initRippleCanvas`)

- 作品サムネイル1枚につき`<canvas>`を1つ用意し、生WebGL(ライブラリ不使用)で画面いっぱいの四角形(quad)にテクスチャを貼っています。
- フラグメントシェーダー内で、正規化したマウス位置`uMouse`とUV座標の距離から**同心円状の波**(`sin`)を計算し、その波の強さぶんだけUVサンプリング位置を放射方向にずらすことで、水面に触れたような歪みを作っています。
- `uStrength`という「ホバー強度」をマウスが乗っている間だけ0→1に、離れると1→0にlerpでアニメーションさせることで、歪みが唐突に出たり消えたりせず、じわっと現れて消えるようにしています。
- **著作権対策**: テクスチャに使う「写真」は実際の画像ファイルではなく、`paintPlaceholderPhoto()`関数が`Canvas2D`でその場生成するオリジナルのグラデーション＋図形イラストです。外部画像は一切ダウンロード・使用していません。

### 3. マグネティック・カスタムカーソル

- 小さな点(`#cursorDot`)は`mousemove`の座標へ即座に追従させ、大きな輪(`#cursorRing`)はlerpで少し遅れて追従させることで、**重さの違う2層のカーソル**を表現しています。
- `data-cursor="View"`のような属性を持つ要素にマウスが乗ると、輪が拡大して塗りつぶされ、属性値がラベルとして中央に表示されます。動的に生成される作品カードにも同じ`bindMagneticCursor()`関数を呼び出すことで、後から追加した要素にも同じ挙動を仕込めるようにしています。

### 4. テキストのリベール表示

- `data-reveal`を付けた要素の中身を`.reveal-inner`でラップし、CSSの`transform: translateY(110%)`で下に隠しておきます。
- `IntersectionObserver`で画面内に入ったことを検知したら`is-inview`クラスを付与し、`transition`でスッと持ち上がるように見せています。

## 使い方(自分のプロジェクトへの組み込み方)

1. `index.html`をそのままコピーして開けば、単体で動作します(外部ライブラリ・ビルド不要)。
2. **慣性スクロールだけ**を自分のページに使いたい場合は、`SmoothScroll`クラスと`#scroll-spacer` / `#scroll-content`のHTML構造・CSS(`position: fixed`)をそのまま持っていけます。`ease`の値を小さくするほど重く滑らかに、大きくするほどキビキビ動きます。
3. **画像リップル効果だけ**を使いたい場合は、`initRippleCanvas(canvas, hue)`を呼び出す前に、`paintPlaceholderPhoto()`を自分の`<img>`要素からテクスチャを読み込む処理に差し替えてください。

   ```js
   // 例: 実際の画像ファイルをテクスチャとして使う場合
   const img = new Image();
   img.crossOrigin = "anonymous";
   img.onload = () => {
     gl.bindTexture(gl.TEXTURE_2D, tex);
     gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, img);
   };
   img.src = "your-photo.jpg";
   ```

4. **マグネティックカーソル**を使い回したい場合は、`.cursor` / `.cursor-ring`のHTML・CSSと`bindMagneticCursor(el)`関数をコピーし、反応させたい要素に`data-cursor="ラベル文言"`属性を付けるだけで動きます。
