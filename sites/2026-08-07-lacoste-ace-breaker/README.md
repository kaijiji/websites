## 評価されている理由・印象的だった点

Ace Breaker が評価されたのは、単に「3Dできれい」なだけでなく、**ブランドサイトなのに本当に遊べるゲームになっている**という完成度の高さです。

- 操作が「左右に動かすだけ」の1つに絞られていて、説明なしでも数秒で遊び方がわかる
- WebGL(Three.js)による3D演出と、Space Invaders / Pong を思わせるレトロなブロック崩しのルールを組み合わせている
- ブロックを壊すたびの爽快なフィードバック(エフェクト・スコア加算・コンボ)がしっかり作り込まれている
- 緑・白・黄色というブランド/テニスコートを想起させる限られた配色で、情報量を絞りつつ視認性の高いUIになっている
- ゲームの結果(スコア)が実際の景品(観戦チケットやポロシャツ)に繋がっており、「遊ぶ理由」がある

## 使われている技術・ライブラリの推測

公開情報や技術記事から、以下の構成が使われていると推測されています。

- **[Three.js](https://threejs.org/)** — WebGLベースの3Dレンダリングライブラリ。コート・ラケット・ボール・ブロックの描画を担当していると考えられます。
- ブラウザ上で完結するミニゲームのため、複雑な物理演算エンジンではなく、**自前のシンプルな当たり判定ロジック**(ボールと矩形のAABB判定など)で十分に成立する設計だと推測されます。
- スコア・コンボ・パワーアップ・残機などの**ゲーム進行管理**は、DOM(HTML/CSS)によるHUDオーバーレイと、Three.jsのシーン更新を組み合わせて実現していると考えられます。

このデモでも同じ考え方(Three.jsによる3D描画 + 自作の当たり判定 + DOM HUD)を採用して再現しています。

## 再現コードの仕組みの解説

`index.html` 1ファイルに、CSS・JavaScript(ES Modules)をすべてインラインで記述しています。処理は大きく分けて次のパートに分かれています。

1. **Three.js の基本セットアップ**(`createRenderer` / `createScene` / `createCamera`) — 見下ろし気味の固定カメラで、テニスコートを斜め上から見るゲーム画面を作ります。
2. **コート・ライン**(`createCourt`) — 床のPlaneGeometryに加え、細長い板を並べてテニスコート風のセンターライン・サイドラインを表現しています。
3. **ラケット(パドル)とボール**(`createPaddle` / `createBall`) — ラケットは箱、ボールは球のシンプルなメッシュです。ボールには半透明の球を複数個重ねた「残像(トレイル)」を実装し、スピード感を演出しています。
4. **ブロックフィールド**(`createBrickField`) — 行×列でブロックを並べ、一部を確率でパワーアップ内蔵ブロック(黄色)にしています。
5. **当たり判定**(`Game.update` 内) — 物理エンジンは使わず、座標同士の距離比較(AABB風の判定)だけで「ボール×壁」「ボール×ラケット」「ボール×ブロック」の反射を計算しています。ラケットに当たった位置(中心からのズレ)によって跳ね返る角度を変えているのが、Breakout系ゲームの定番テクニックです。
6. **パーティクル演出**(`createParticlePool`) — ブロックを壊すたびに、小さな立方体を複数個「速度 + 重力」で飛ばして破片のように見せています。オブジェクトプール(あらかじめ作っておいたメッシュを使い回す)方式にすることで、毎回 `new` して負荷をかけずに済むようにしています。
7. **カメラシェイク**(`createShake`) — 「基準カメラ位置」に、時間とともに減衰するランダムな揺れを加算するだけの軽量な実装です。ヒット時にこの関数を呼ぶだけで、画面に「衝撃」が伝わる演出になります。
8. **HUD(スコア・コンボ・残機・パワーアップ通知)** — Three.jsのCanvasの上に重ねたHTML/CSSのオーバーレイとして実装しています。3D描画とUIを分離することで、テキストの視認性を保ちながら演出を作り込めます。
9. **メインループ** — `requestAnimationFrame` の中で経過時間(dt)を計算し、ラケット追従・ボール移動・当たり判定・パーティクル・カメラシェイクを毎フレーム更新してから描画しています。

### つまずきやすいポイント（実装時に直面した問題と対策）

- **ラケットの反射角**: 単純に「壁のように跳ね返す」だけだとゲームとして単調になります。ラケット中心からのズレ(`offset`)を角度に変換して反射方向を決めることで、狙って打ち返す面白さが生まれます。
- **パーティクルの生成コスト**: 毎回 `new THREE.Mesh()` するとブロックを連続で壊したときにガベージコレクションの負荷でカクつきます。あらかじめ固定数のメッシュを用意しておき、使い回す「オブジェクトプール」にすることで解決しています。
- **コンボ表示のちらつき**: スコア加算のたびに `setTimeout` をリセットしないと、コンボ表示が意図せず早く消えてしまいます。`clearTimeout` を必ず呼んでからタイマーを再設定しています。

## 使い方（コピーしてすぐ使う手順）

1. このフォルダ（`index.html` と `vendor/` フォルダ）をまるごと自分のプロジェクトにコピーします。
2. ローカルサーバーで配信して開きます（`file://` で直接開くと ES Modules / importmap の読み込みでエラーになる場合があります）。

   ```bash
   cd sites/2026-08-07-lacoste-ace-breaker
   python3 -m http.server 8080
   # ブラウザで http://localhost:8080 を開く
   ```

3. PLAYボタンを押してスタートし、マウス(PC)またはタッチ操作(スマートフォン)でラケットを左右に動かします。
4. 黄色いブロックを壊すとラケットが一時的に大きくなる「WIDE RACKET」パワーアップが発動します。
5. カスタマイズしたい場合は、ファイル冒頭の定数（`COURT` / `PADDLE` / `BRICK` / `COLORS`）を書き換えるだけで、コートのサイズやブロックの数、配色を簡単に変更できます。パワーアップの出現確率は `createBrickField` 内の `Math.random() < 0.12` の値を調整してください。

### vendor フォルダについて

`vendor/three.module.min.js` は、npm 公式レジストリで配布されている MIT ライセンスのオープンソースライブラリ（Three.js）をそのまま同梱したものです。対象サイトの著作物ではなく、誰でも自由に利用できるライブラリなので、自分のプロジェクトでもそのまま使えます。バージョンを更新したい場合は [three.js](https://www.npmjs.com/package/three) の npm パッケージを取得し直してください。
