## 評価されている理由・印象的だった点

検索結果から読み取れる紹介文では、Susurrusは「Three.js/WebGLの3D体験を、まるで水彩画のように見せる」という一点に振り切ったプロジェクトとして評価されています。

- クリームとセピアがかった水彩画のような色調の世界に、風車の浮かぶ小さな島が佇み、水面の上をインクが滲むように光や色がゆっくり動く、瞑想的(meditative)な雰囲気
- 一見素朴で"cozy"(居心地よい)だが、よく見ると少し不思議(surreal)という、静かなナラティブ
- **表現の核となる技術**: パーティクルや大量のポストエフェクトを重ねるのではなく、**Kuwaharaフィルタ(黒澤フィルタ)というただ1つのポストプロセッシングパス**だけで、3DレンダリングをNPR(Non-Photorealistic Rendering / 非写実的レンダリング)に変換している点
- モバイルでも滑らかに動くよう、水面反射などを低解像度で描画するなど、パフォーマンスと見た目の質感を両立させる工夫

このデモでは、上記のうち「Kuwaharaフィルタによる水彩画変換」を主役に据え、それを引き立てるための最小限の3Dシーン(島・風車・水面)・トゥーン風ライティング・紙の質感グレーディング・マウス追従カメラ・環境音の5つを、外部ライブラリなしのバニラJS/CSS/WebGLで再現しています。

## 使われている技術・ライブラリの推測

検索結果の要約から確認できた情報は以下の通りです。

- **Three.js** — Blenderで作ったジオメトリをWebGL上に描画する3Dエンジン
- **Kuwaharaフィルタ**(異方性版 / Anisotropic Kuwahara Filtering)— プロジェクト唯一のポストプロセッシングパスとして、レンダリング結果を絵画的な質感に変換
- **MeshReflectorMaterial 相当の水面表現** — 低解像度で反射を描画し、その上にアニメーションする専用シェーダーの平面を重ねてディテールを追加(パフォーマンス最適化のための工夫として紹介されていました)
- サウンドデザイン・インタラクションの実装(詳細は非公開)

このデモでは、Three.jsを使わず**素のWebGL(生のGLSL)とバニラJavaScript・CSSだけ**で、「3Dシーン → Kuwaharaフィルタ → 紙質感グレーディング」という3段パイプラインの骨格を再現しています。実サイトが使っているのはGPU向けに改良された**異方性**Kuwaharaフィルタですが、このデモでは原理を学びやすいよう、教科書的な**等方(4象限)**版をゼロから実装しています。

## 再現コードの仕組みの解説

`index.html` 1ファイルに CSS・JavaScript をすべてインラインで記述しています。実装は、他のプロジェクトにもそのままコピーできる小さな関数の集まりとして書かれています。

1. **`createSceneRenderer(gl)` — ローポリ3Dシーンの描画**
   島(円錐台)・風車の塔(円錐台)・回転する4枚の羽根(直方体)・木(円錐台×2)・水面(グリッド平面)をすべて自前のジオメトリ生成関数(`makeConeFrustum` / `makeBox` / `makeGrid`)で組み立て、フレームバッファ(テクスチャ)へ描画します。陰影は `floor(NdotL * 3.0) / 3.0` で3段階に量子化した「トゥーン風ライティング」にしています。これは見た目の演出であると同時に、次工程のKuwaharaフィルタが「均一な色の塊」を見つけやすくするための下準備でもあります。水面だけは専用のシェーダーで、頂点シェーダー内の `waveHeight()` 関数(2方向のサイン波の合成)から解析的に法線を計算し、リアルタイムに揺れる水面を作っています。
2. **`createKuwaharaPass(gl)` — このデモの主役、水彩化フィルタ**
   各ピクセルの周囲を上下左右4つの象限に分割し、それぞれの領域の平均色と分散(色のばらつき)をGLSLループで計算します。最終的な色には「分散が最も小さい = 最も均一な」象限の平均色を採用します。模様が細かく色が変化する場所(輪郭付近)ではどこかの象限が必ず均一になるためエッジが保たれ、逆に色が均一な場所は大きな塊としてベタ塗りされます。これが絵の具の筆致のような質感を生む仕組みです。半径(サンプリング範囲)は `uRadius` というuniformでスライダーからリアルタイムに変更できます。
3. **`createGradePass(gl)` — 紙の質感への仕上げ**
   Kuwaharaフィルタの出力に対して、クリーム寄りの色被せ・わずかな彩度ダウン・`hash()`関数による紙の粒状ノイズ・画面端を暗くするビネットを加えて、最終的にcanvasへ描画します。
4. **`createRenderTarget` / `RENDER_SCALE`によるパフォーマンス最適化**
   Kuwaharaフィルタは1ピクセルあたり最大 `4 × 7 × 7 = 196` 回のテクスチャサンプリングを行う重い処理のため、3Dシーンとフィルタ結果は実際の画面解像度の62%(`RENDER_SCALE = 0.62`)で描画し、最後の仕上げパスで画面いっぱいに引き伸ばしています。これは実サイトの「水面反射を低解像度で描いてパフォーマンスを確保する」という工夫からヒントを得たテクニックです。
5. **マウス追従カメラ(`camState.yaw` / `camState.pitch`)**
   マウス座標を`-1〜1`に正規化し、目標のヨー角・ピッチ角へ毎フレーム`lerp`(線形補間)で少しずつ近づけることで、カーソルを動かすとカメラがゆっくり寄り添うように視点を変える演出にしています。自動でゆっくり回り続けるアイドルモーションも同じ角度に加算しています。
6. **`createWindAmbience()` — Web Audioによる環境音**
   2秒分のホワイトノイズバッファを作り、ループ再生した上で`BiquadFilterNode`(ローパスフィルター)を通すことで「サー」という風のような音を作っています。`AudioContext`はブラウザの自動再生ポリシー上、ユーザー操作(ボタンクリック)なしには開始できないため、トグルボタンのクリックイベント内で生成しています。

### つまずきやすいポイント(実装時に直面した問題と対策)

- **ネットワーク制限で実サイトを直接見られなかった**: このセッションの実行環境では `susurrus.vercel.app`・`awwwards.com`・`tympanus.net`・`wikipedia.org` など、調査に使いたかったサイトへの直接アクセスがすべてネットワークポリシーでブロックされていました(`EGRESS_BLOCKED`)。そのため検索結果のスニペット(受賞歴・使用技術・Codrops記事の要約)のみを根拠に設計しており、実サイトの正確な3Dモデル・カメラワーク・配色までは確認できていません。このデモは「公開情報から読み取れる範囲での技法の解釈による再現」であり、実サイトの完全な再現ではないことにご留意ください。
- **WebGL ES 1.00 のループはuniformで直接回せない**: GLSL ES 1.00は`for`ループの反復回数がコンパイル時に決まっている必要があり、`uRadius`(uniform)をそのままループ上限に使えません。定数`KUWAHARA_MAX_RADIUS`まで固定回数ループしつつ、ループ内で`if (float(i) > radius) break;`として実際の反復数を動的に絞り込む、という定番のイディオムで解決しています。
- **Kuwaharaの4象限が中心ピクセルを二重に数える**: シンプルな実装では4つの象限すべてが中心ピクセル(オフセット0,0)を含んでしまい、厳密なアルゴリズムとはズレます。教科書的な等方Kuwaharaでもこの近似はよく使われており、体感できるほどの破綻がないため、学習用デモとしてはそのまま採用しています。より精度を求める場合は象限ごとに重複しないオフセット範囲(例: 0象限は`-r..-1`のみ)にすると改善できます。
- **量子化した陰影とフィルタの相性**: 最初は通常のグラデーション陰影で試しましたが、Kuwaharaフィルタをかけても「塊」感が弱く、ただぼやけただけの見た目になってしまいました。陰影を3段階に量子化(トゥーン化)してから通すことで、フィルタが拾える「均一な色面」がはっきりし、絵の具で塗ったような質感が強く出るようになりました。

## 使い方(コピーしてすぐ使う手順)

1. `index.html` を1ファイルごと自分のプロジェクトにコピーします(外部ライブラリ・画像・フォントへの依存は一切ありません)。
2. そのままダブルクリックで `file://` として開いても動作します。ローカルサーバー経由で見る場合は以下のようにします。

   ```bash
   cd sites/2026-08-08-susurrus-watercolor-kuwahara
   python3 -m http.server 8080
   # ブラウザで http://localhost:8080 を開く
   ```

3. 右下パネルの「絵筆の粒度(半径)」スライダーで、Kuwaharaフィルタの効き具合(0=フィルタなしに近い〜6=大きな筆致)をリアルタイムに調整できます。
4. 「水彩 ON/OFF」ボタンで、フィルタ適用前(生の3Dトゥーンレンダリング)との見比べができます。仕組みを学ぶ際に、ぜひこのボタンでBefore/Afterを切り替えてみてください。
5. **既存のThree.js/WebGLプロジェクトにKuwaharaパスだけを移植したい場合**は、`KUWAHARA_FS`(フラグメントシェーダー文字列)と `createKuwaharaPass(gl)` 関数だけをコピーし、自分のレンダリング結果を書き込んだテクスチャを `kuwaharaPass.render(target, sourceTexture, radius)` に渡すだけで組み込めます。
6. 色味(クリーム/セピアの強さ)を変えたい場合は `GRADE_FS` 内の `color *= vec3(1.05, 0.99, 0.88)` と彩度ダウンの `mix(color, vec3(luma), 0.12)` の数値を調整してください。
7. 島や風車のレイアウトを変えたい場合は `createSceneRenderer` 内の `trees` 配列(位置・大きさ)や、風車の位置を決めている `mat4.translate(towerModel, 0.3, 1.05, -0.2)` の数値を書き換えるだけで反映されます。
8. 環境音の質感を変えたい場合は `createWindAmbience()` 内の `filter.frequency.value`(ローパスのカットオフ)や `gain.gain.linearRampToValueAtTime` の目標音量を調整してください。
