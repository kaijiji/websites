# Kin(制作: By-Kin) — エディトリアル・モーション再現デモ

- **サイト名**: Kin（インテリア/ブランディング/グラフィックデザインを手がける英国のクリエイティブスタジオ By-Kin のポートフォリオサイト）
- **参照元URL**: https://www.by-kin.com/
- **Awwwardsページ**: https://www.awwwards.com/sites/kin-2

## 評価されている理由・印象的だった点

このサイトは以下の4冠を獲得しています。

- Awwwards **Site of the Day**
- Awwwards **Developer Award**（一般投票ではなく審査員が「エンジニアリングの質」だけを評価して贈る賞）
- FWA
- CSS Design Awards **Web of the Day**

特にDeveloper Awardは「見た目の派手さ」ではなく、コマ送りで見ても破綻しないモーションの精度、ミドルスペックのPCでも滑らかに保たれるパフォーマンス、そして画面遷移のたびに再構築されないUIの一貫性が評価されるものです。By-Kinのサイトは、抑制のきいたエディトリアル・タイポグラフィ、重みを感じる慣性スクロール、そして「注意を引かない」トランジションによって、ページ全体が**1枚の連続した面**であるかのような体験を作り出している点が高く評価されています。作品(=インテリアデザインの写真)を演出が邪魔しない、という設計思想が徹底されているのも特徴です。

## 使われている技術・ライブラリの推測

公開情報から推測される技術スタックです。

- **Next.js** — フロントエンドフレームワーク
- **GSAP** — スクロール連動アニメーションやタイムライン制御
- **Lenis**（darkroomengineering製のスムーススクロールライブラリ）— 慣性のある「重み」を持つスクロール体験
- **Strapi** — ヘッドレスCMS。プロジェクトやジャーナル記事をデプロイなしで更新できる構成

## 再現コードの仕組み

著作権上の理由から、上記ライブラリや By-Kin 自身のソースコードは一切使用/転載していません。代わりに、観察した「体験の仕組み」を理解した上で、**依存ライブラリなしのバニラJS**で同じ効果を再現しています(`index.html` 内に4つの独立した機能としてコメント付きで実装)。

### 1. `SmoothScroll` クラス — 重みのある慣性スクロール
実際のコンテンツを `position: fixed` にして裏で `transform: translateY()` を動かし、見えない `spacer` 要素だけがブラウザ本来のスクロールバー(高さ)を担当します。毎フレーム、目標スクロール位置 (`target`) へ現在位置 (`current`) を一定割合(`ease`)だけ近づける「線形補間(lerp)」を行うことで、Lenisのような「後から追いついてくる」重みのあるスクロール感を再現しています。

### 2. `SplitTextReveal` 関数 — 見出しの単語単位リビール
`.split-line` 要素のテキストを単語ごとに `<span>` へ分割し、`IntersectionObserver` で画面内に入ったタイミングで各単語を `translateY` + `opacity` のCSS transitionで下から現れさせます。単語ごとに `transition-delay` をずらすことで、GSAPのSplitText+staggerに近い段差のある登場アニメーションを作っています。

### 3. `initImageRevealOnScroll` 関数 — 画像のマスク・リビール
カード要素が画面に入ると `clip-path: inset(0 0 100% 0)` から `inset(0 0 0% 0)` へCSS transitionで変化させ、画像(このデモではプレースホルダーのグラデーション)が下から上へマスクを開くように現れます。By-Kinのサイトで見られる「クロップではなくマスク/リビールで見せる」演出の考え方を再現したものです。

### 4. `initPersistentHeaderRouter` 関数 — ヘッダーを保ったページ遷移
ナビゲーションのリンクをクリックしても `<nav>` 要素自体は一切再生成されません。`#page-content` 内の `.page` 要素だけをフェードアウト→表示切替→フェードインさせることで、通常のページ遷移にありがちな「リロード感」を消し、常に同じ1枚の面の上でコンテンツだけが入れ替わっているように見せています。

## 使い方(コピーしてすぐ使う手順)

1. `index.html` をそのまま自分のプロジェクトにコピーします。
2. ブラウザで開くだけで動作します(外部ライブラリ不要)。
3. 各機能は独立した関数/クラスなので、必要なものだけを抜き出して使えます。
   - 慣性スクロールだけ使いたい → `SmoothScroll` クラスと対応するCSS(`#scroll-content`, `#scroll-spacer`)をコピー
   - 見出しの単語リビールだけ使いたい → `.split-line` のCSSと `initSplitTextReveal()` をコピー
   - 画像のマスク・リビューだけ使いたい → `.card .frame` のCSSと `initImageRevealOnScroll()` をコピー
   - ヘッダー固定のページ遷移だけ使いたい → `data-page` 属性の付け方と `initPersistentHeaderRouter()` をコピー
4. 自分のコンテンツ(画像・テキスト)に差し替えて調整してください。`ease` の値を小さくするほどスクロールが「重く」なり、大きくするほど「軽快」になります。
