# Isometric Basement Room — 歩き回れるアイソメトリック3Dルーム 再現デモ

## 参照元サイト

- **サイト名**: basement.studio(アルゼンチン拠点のデジタルスタジオ「Basement Studio」の自社サイト。Vercel・Mr. Beast・Kid Super 等の海外テック/クリエイター企業のブランディング・Web制作を手がける)
- **URL**: https://basement.studio/
- **受賞歴**: Awwwards *Site of the Day*(2025年4月)、Awwwards Honorable Mention(2025年11月)ほか、過去の複数バージョンでも受賞歴のあるスタジオです。

> **本フォルダのコードは学習目的のオリジナル実装です。** 参照元サイトの実際のテクスチャ・3Dモデル・テキスト・配色の正確な値・ソースコードは一切コピーしていません。
>
> **調査方法についての正直な注記:** このセッションのネットワーク環境では `basement.studio` 本体および `awwwards.com` への直接アクセスがネットワークポリシーでブロックされており、実際にレンダリングされたサイトを目視することはできませんでした。代わりに、Basement Studio 自身が公開している **サイトのソースコード一式のGitHubリポジトリ**([`basementstudio/website-2k25`](https://github.com/basementstudio/website-2k25))を閲覧し、`src/components/` 以下のフォルダ構成(`custom-cursor` / `inspectables` / `camera`(`wasd-controls.tsx` を含む) / `arcade-board` / `arcade-game` / `doom-js` / `locked-door` / `speaker-hover` / `godrays` / `sparkles` / `weather` など約40個のコンポーネント群)や `custom-cursor/index.tsx` の実装(Zustand + Framer Motion によるバネ追従カーソルと `[ ]` 括弧ラベル表示・マーキー表示)を読むことで、「どんな体験の仕組みが使われているか」を把握しました。あわせて design ギャラリーサイト(MaxiBestOf)の要約情報から配色(オレンジ・グレー・ダーク基調)とフォント(PP Neue Montreal)の傾向も参考にしています。**このリポジトリのコード自体は読解のみに使い、1行もコピーしていません。** 見た目の細部(色の正確な値・レイアウト・文言)はすべてこのデモのためにゼロから独自に設計したものです。

## 評価されている理由・印象的だった点

調査で判明したコンポーネント構成から、basement.studio のサイトは単なる「かっこいいヒーロー演出」ではなく、**サイト全体が1つの探索可能な3D空間(まさに「地下室(basement)」)になっている**ことが分かります。

- WASD キー(`wasd-controls.tsx`)で3D空間の中を移動できる、Webサイトというよりゲームに近い操作性
- 部屋のあちこちに置かれた物(アーケード筐体、バスケットゴール、鍵のかかったドア、置き物、スピーカー、ペット、季節限定のクリスマスツリーなど)が `inspectables`(調べられるもの)として個別に実装されており、それぞれ違う反応をする
- マウスを動かすだけで文脈に応じたラベル(「見る」「再生する」など)が `[ ]` の角括弧付きで浮かび上がるカスタムカーソル。音が鳴る要素の上ではラベルがマーキー(横スクロール)表示に切り替わる芸の細かさ
- `godrays`(光条)や `sparkles`(きらめき粒子)といった専用の後処理コンポーネントで、単なる3Dモデル表示に留まらない「空気感」を作り込んでいる
- 隠しコマンド的に `doom-js` という往年の名作FPSゲームのイースターエッグまで仕込まれているなど、「作り込みの密度で魅せる」姿勢がAwwwardsで評価されているポイントだと考えられます

## 使われている技術・ライブラリの推測

GitHubリポジトリで確認できた実際の技術スタックは以下の通りです(これは推測ではなく、公開リポジトリの設定ファイルから直接確認した事実です)。

- **Next.js + TypeScript** — サイト全体のフレームワーク
- **React Three Fiber(Three.js)** — 3Dシーンの描画(`src/shaders` 以下に `material-postprocessing` や `material-screen` 等の独自GLSLシェーダー群あり)
- **Zustand** — カーソルの状態(ホバーテキスト・カーソル種別)などのグローバル状態管理
- **Framer Motion** — カーソルのバネ(スプリング)追従アニメーションや、要素の出現・消失トランジション
- **Tailwind CSS / Sanity CMS** — スタイリングとコンテンツ管理

このデモでは上記のような重量級の構成(React Three Fiber・Zustand・Framer Motion)は使わず、**ライブラリを一切使わないバニラJavaScript + `<canvas>` の2Dコンテキストだけ**で「探索できるアイソメトリック風3D空間」「バネ追従するカスタムカーソル」「クリックで調べられるオブジェクト」という3つの体験の骨格だけを抽出して再現しています。フレームワークがなくても仕組みそのものは十分に学べる、という点を重視しました。

## 再現コードの仕組みの解説

`index.html` 1ファイルにHTML・CSS・JavaScriptをすべてインラインで記述しています。外部ライブラリへの依存はゼロです。

### 1. アイソメトリック投影(`project()` 関数)

3D空間の座標 `(x, y, z)` を2Dのスクリーン座標に変換する処理を、行列ライブラリなしで直接計算しています。

```js
function project(x, y, z, cam) {
  const dx = x - cam.x, dz = z - cam.z;
  const s = TILE * cam.zoom;
  const screenX = (dx - dz) * s * 0.866; // cos(30deg)
  const screenY = (dx + dz) * s * 0.5 - y * s;
  return { x: screenX + cam.originX, y: screenY + cam.originY };
}
```

これは「2:1アイソメトリック」と呼ばれる、レトロなシミュレーションゲームなどで古くから使われる古典的な変換式です。`cam.x` / `cam.z` を変化させるだけで「カメラが部屋の中を移動しているように見える」演出になり、`cam.zoom` を変化させるだけで「ズームイン/ズームアウト」になります。

### 2. 立方体の描画と「画家のアルゴリズム」

すべての家具は直方体(ボックス)の組み合わせとして表現しています。1つの直方体につき、見える3面(上面・右面・前面)だけをそれぞれ別の明るさで塗ることで立体感を出しています(`shade()` 関数で色を明るく/暗くしています)。

奥にあるものから手前にあるものへと順番に描画する「画家のアルゴリズム(Painter's Algorithm)」でオブジェクトを重ね塗りすることで、Zバッファのような複雑な仕組みなしに正しい前後関係を再現しています。このデモでは `(x + z)` の値が大きいほど手前と判定してソートしています。カメラを動かしても全オブジェクトが同じだけ平行移動するだけなので、前後関係は変わりません。そのため**ソートは初期化時に1回行うだけ**で済む、という最適化もポイントです。

### 3. バネ追従するカスタムカーソル([ ]ラベル付き)

`custom-cursor/index.tsx` の解析から分かった「Framer Motionのスプリングでカーソルを追従させ、ホバー時に `[ラベル]` 形式のテキストを表示する」という体験を、`requestAnimationFrame` ループ内の単純な指数減衰(線形補間)で再現しています。

```js
cursorPos.x += (mouse.x - cursorPos.x) * 0.28;
cursorPos.y += (mouse.y - cursorPos.y) * 0.28;
```

本物の物理バネ(スプリング)ではありませんが、「目標値に毎フレーム一定割合だけ近づける」だけで、遅れて追従する滑らかな動きが得られます。スピーカーにホバーした時だけ CSS の `@keyframes marquee` でラベルをマーキー(横スクロール)表示に切り替える処理も含めており、実サイトの「音が鳴る要素だけラベル表示が変わる」という細部の作り込みも再現しています。

### 4. 簡易レイキャスト(当たり判定)とクリックで開く詳細パネル

WebGLの `Raycaster` は使わず、各オブジェクトの8つの頂点をすべて2Dに投影し、その外接矩形(バウンディングボックス)とマウス座標を比較するだけの簡易的な当たり判定にしています。実運用では正確な多角形判定やWebGLレイキャストが望ましいですが、学習用途としては「3D空間上の当たり判定は、結局は2Dスクリーン座標の比較に帰着できる」という考え方が伝わるよう、あえてシンプルな実装にしています。

クリックすると `inspecting` 状態になり、カメラの注視点とズーム値をそのオブジェクトに向けて `lerp` で寄せながら、背景をぼかした半透明パネル(`backdrop-filter: blur()`)をフェード表示します。実サイトの `inspectable-viewer` コンポーネントが持つ「対象にフォーカスして詳細を見せる」という体験の骨格を、CSSトランジションと `lerp` だけで模倣しています。

### 5. 補助演出(灯り・パーティクル)

ランプをクリックすると `THREE.PointLight` 相当のことを `createRadialGradient` によるにじみ塗りで再現し、`godrays` コンポーネントが作る「その場だけ明るくなる」空気感を簡易的に表現しています。また、常時ふわふわと上昇する半透明の小さな円(`particles` 配列)で `sparkles` コンポーネントに相当する環境演出も加えています。

## 使い方(コピーしてすぐ使う手順)

1. `index.html` をまるごと自分のプロジェクトにコピーしてください。外部ライブラリの読み込みは一切不要です。
2. 家具やオブジェクトの構成を変えたい場合は、スクリプト内の `ROOM_OBJECTS` 配列を書き換えます。各要素は次の形式です。

   ```js
   {
     id: "任意のID",
     kind: "panel" | "toggle" | "speaker", // クリック時の挙動
     label: "ホバー時に表示する動詞(例: 見る)",
     title: "panelの場合: パネルの見出し",
     body: "panelの場合: パネルの本文",
     boxes: [ { x, y, z, w, h, d, color }, ... ], // 直方体の組み合わせ
   }
   ```

   例えば「作品カードを部屋の中に配置して、クリックすると作品詳細パネルが開くポートフォリオサイト」のような応用も、`kind: "panel"` のオブジェクトを増やすだけで作れます。
3. 床の広さは `FLOOR_N` の値、移動できる範囲は `updateCamera()` 内の `clamp(..., -3.5, 3.5)` を変更することで調整できます。
4. ブラウザで直接 `index.html` を開くだけで動作します(ビルドツール不要)。WASD または矢印キーで移動、オブジェクトにカーソルを合わせてクリックすると詳細パネルが開きます(Escキーまたは背景クリックで閉じます)。
