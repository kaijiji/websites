## 評価されている理由・印象的だった点

Serotoninn のサイトは「グラム(華やかさ)とグランジ(退廃的な質感)の間」という、ブランドが掲げる世界観をそのままUIの手触りに変換している点が高く評価されています。

- 大胆で作り込まれたビジュアル密度: フルスクリーンの映像、アニメーション遷移、装飾ディテールが何層にも重なっている
- ナイトライフ/アンダーグラウンドファッションを思わせる、黒と差し色2色に絞った潔い配色設計
- インタラクティブなナビゲーション(スクロール方向でヘッダーを隠す/見せる、メニューが大胆に展開する)
- Swiper.js を使ったルック(コーディネート)ギャラリーなど、EC/ルックブックとしての実用性と演出性の両立
- 「見た目のインパクト」だけでなく、操作するたびに気持ちよいマイクロインタラクション(カーソル追従など)が細部まで作り込まれている

## 使われている技術・ライブラリの推測

Awwwards・Communication Arts の紹介記事から、以下の技術構成が使われていると公開されています。

- **WordPress** — CMSとしてコンテンツ管理を担当していると考えられます。
- **[GSAP](https://gsap.com/)** — スクロール連動のテキストリベールや、ページ内トランジション、要素のstagger(順番ずらし)アニメーションに使われていると推測されます。
- **[Swiper.js](https://swiperjs.com/)** — ルックブック(商品カット一覧)のスライダー/横スクロールギャラリーに使われていると推測されます。

このデモでは、これらのライブラリの「仕組み」を理解した上で、**外部ライブラリに依存しないバニラJavaScript**で再実装しています。GSAPのScrollTrigger相当は`IntersectionObserver`、Swiper相当は`position: sticky`を使った「ピン留め横スクロール」で代替しました。単一HTMLファイルでコピーしてすぐ動かせるようにするための選択です。

## 再現コードの仕組みの解説

`index.html` 1ファイルに CSS・JavaScript をすべてインラインで記述しています。実装は、それぞれ独立して他プロジェクトにもコピーできる小さな関数の集まりとして書かれています。

1. **`initGrain(canvas)` — フィルムグレイン(粒状ノイズ)オーバーレイ**
   画面全体を覆う `<canvas>` に、低解像度(表示サイズの1/4)でランダムな白黒ノイズを90msごとに描画し、`mix-blend-mode: overlay` で下のコンテンツに馴染ませています。解像度を落としてCSSで引き伸ばすことで、フルHD相当の画素をすべて計算するより軽く動きます。

2. **`initCustomCursor()` — ドット + 追従リングのカスタムカーソル**
   小さいドットはポインタ座標にそのまま追従し、大きいリングは毎フレーム `ring += (mouse - ring) * 0.16` という線形補間(lerp)でリングをゆっくり追いかけさせています。これだけで「少し遅れてついてくる、粘性のある」カーソルになります。`data-cursor="view"` を持つ要素(ルックブックのカードなど)にホバーすると、リングが拡大して「VIEW」の文字を表示します。

3. **`splitIntoChars()` / `splitIntoWords()` — キネティックタイポグラフィ**
   見出しのテキストを1文字(または1単語)ずつ `<span>` に分解し、各 span に CSS変数 `--i`(出現順インデックス)を注入します。CSS側は `transition-delay: calc(var(--i) * 28ms)` のように、そのインデックスを遅延時間に変換するだけ。これだけで「文字が順番にせり上がる」ストップモーション風の演出が実現できます。GSAPの `SplitText` + `stagger` オプションがやっていることの最小構成版です。

4. **`observeReveal()` — スクロール連動リベール**
   `IntersectionObserver` で要素が画面に入った瞬間を検知し、CSSクラス(`is-in`)を1回だけ付与します。GSAPの `ScrollTrigger` は内部でスクロール位置とビューポート交差を細かく計算していますが、「一度画面に入ったらアニメーションさせる」という用途だけなら、ブラウザ標準APIのIntersectionObserverで十分再現できます。

5. **`initHideOnScrollNav()` — 下スクロールで隠れるヘッダー**
   直前のスクロール位置と現在位置を比較し、下方向にスクロールしていればヘッダーを `translateY(-120%)` で隠し、上方向ならすぐ再表示します。ファッション/ラグジュアリー系サイトで、コンテンツをできるだけ広く見せるために使われる定番パターンです。

6. **`initMenuOverlay()` — フルスクリーンメニュー**
   ボタンクリックで `clip-path: circle()` の半径を 0% → 150% にトランジションさせ、ボタンの位置を起点に画面全体がじわっと展開するように見せています。メニュー項目は開くたびに `--i` に応じた `transition-delay` で下から順にせり上がります。

7. **`initPinnedHorizontalGallery()` — ピン留め横スクロールギャラリー(ルックブック)**
   外側の `.lookbook-spacer` に画面の3.4倍の高さ(`340vh`)を確保し、内側の `.lookbook-sticky` を `position: sticky; top: 0` で画面に固定します。`requestAnimationFrame` ループの中でスペーサーの `getBoundingClientRect().top` からスクロール進捗(0〜1)を計算し、その割合ぶんだけ内側の `.lookbook-track` を `translateX` で横に動かします。「縦スクロールを横移動に変換する」、Swiper + ScrollTrigger の組み合わせでよく使われるテクニックの素の実装です。進捗バーも同じ `progress` 値からそのまま幅を計算しています。

### つまずきやすいポイント（実装時に直面した問題と対策）

- **`position: absolute` の基準要素忘れ**: `.scroll-hint` を `.hero` の左下に置くつもりが、`.hero` に `position: relative` を指定し忘れて、ページ全体の左下(bodyの末尾)に飛んでいってしまいました。`position: absolute` を使う要素は、必ず親に `position: relative`(などの positioned な指定)を設定することを徹底する必要があります。
- **ピン留めギャラリーの横幅計算**: `scrollWidth` はレイアウト確定後でないと正しい値が取れないため、画像を含む場合は `load` イベント後に再計算する必要があります(本デモはCSSグラデーションのみなので即座に確定します)。
- **カーソルの当たり判定漏れ**: `data-cursor="view"` を後からJSで動的に生成する要素(ルックカード)に付ける場合、`initCustomCursor()` 内のホバー登録処理より **前に** カード生成を済ませておく必要があります。初期化の順番(グレイン→カーソル→テキスト分割→ナビ/メニュー→ギャラリー生成)には意味があります。

## 使い方（コピーしてすぐ使う手順）

1. `index.html` を1ファイルごと自分のプロジェクトにコピーします(外部ライブラリ・画像への依存は一切ありません)。
2. そのままダブルクリックで `file://` として開いても動作しますが、`fetch` を使う拡張をする予定がある場合はローカルサーバー経由を推奨します。

   ```bash
   cd sites/2026-08-07-serotoninn-brand-universe
   python3 -m http.server 8080
   # ブラウザで http://localhost:8080 を開く
   ```

3. 見出しの文言は `<h1 class="kinetic-title" data-kinetic>` や `<h2 class="reveal-lines" data-reveal>` の中身を書き換えるだけで、分割・アニメーションはJS側が自動で行います。
4. ルックブックの枚数や色は、`initPinnedHorizontalGallery()` 内の `palettes` 配列(グラデーションの配列)を増減・変更するだけで調整できます。実際の商品画像を使う場合は `card.style.background` の代わりに `<img>` を追加してください。
5. 配色を変えたい場合は、`:root` の `--bg` / `--fg` / `--accent` の3つのCSS変数を書き換えるだけで、カーソル・アクセント・メニュー背景など全体に反映されます。
6. カスタムカーソルはタッチデバイスでは無効化されるように `@media (hover: none), (pointer: coarse)` を用意済みです。
