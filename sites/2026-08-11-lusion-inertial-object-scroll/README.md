# Lusion — 慣性オブジェクト × スクロール奥行き演出（再現デモ）

## 参照元

- サイト名: **Lusion**（スタジオ自身のポートフォリオサイト）
- URL: https://lusion.co/
- Lusion は、リアルタイムWebGL表現を専門とするクリエイティブスタジオ（創業者: Edan Kwan）。自社サイトは Awwwards / FWA / CSS Design Awards で **Site of the Year** を獲得しており、GLSLやThree.jsを学ぶ人にとって「デベロッパーツールで開いて仕組みを覗き込みたくなる」定番のお手本としてもたびたび紹介されています。

> **著作権について**: このフォルダのコードは Lusion の実際のソースコード・3Dモデル・シェーダー・文言を一切コピーしていません。観察できる「表現の仕組み」だけを自分の理解に基づいて解釈し、ゼロから独自に書き直したオリジナルの学習用デモです。

## 何が評価されているか・印象的な点

Lusion のサイトが繰り返し評価されているのは、次のような点です。

1. **たった1つの3Dオブジェクトを主役にする潔さ**
   ヒーローセクションに置かれた抽象的な立体物が、派手なパーティクルや大量のモデルに頼らず、その質感と動きだけで画面を支配しています。
2. **「軽い」ではなく「重い」インタラクション**
   マウスを動かすとオブジェクトが回転しますが、カーソル位置に瞬時にスナップするのではなく、少し遅れてから収束していきます。これにより、実体のある物体を指で転がしているかのような“質量”を感じさせます。
3. **スクロール = カメラの前進**
   多くのサイトはスクロールでコンテンツを上下にスライドさせますが、Lusion はカメラそのものをZ軸方向（奥行き）に動かします。まるでオブジェクトの近くを通り抜けながら物語を進んでいくような感覚が生まれます。

## 使われていると推測される技術・ライブラリ

- **Three.js**（WebGLの薄いラッパー）による3Dオブジェクトのレンダリング
- 物理ベースレンダリング（PBR）に近いマテリアルと、環境マップ（HDRI）による金属的な反射表現
- GSAP など、スクロール位置とカメラ位置・パラメータを同期させるためのアニメーションライブラリ
- カスタムカーソルやマグネティックボタンのためのポインター座標に対する独自JS処理

このデモでは、上記を学習目的でゼロから理解し直すために、**Three.jsやGSAPなどの外部ライブラリを一切使わず**、生のWebGL2 APIとバニラJavaScriptだけで同じ「仕組み」を再現しています。ライブラリを使わないことで、「内部で何が起きているか」が全部コードとして読めるようにしてあります。

## 再現コードの仕組み

`index.html` 1ファイルで完結しています。大きく6つのパートに分かれています。

### 1. 自前の行列演算（`mat4`）
Three.js を使わない代わりに、透視投影 (`perspective`)・視点行列 (`lookAt`)・回転行列 (`rotationXY`) という必要最小限の4x4行列関数だけを自分で実装しています。WebGLは列優先(column-major)でFloat32Arrayを扱う、という点が学習ポイントです。

### 2. オブジェクト形状の生成（`createOrganicIcosphere`）
1. 正20面体（12頂点・20面）を用意する
2. 三角形の各辺の中点を球面上に正規化しながら追加し、細分割を繰り返して滑らかな球にする（アイコスフィア）
3. 各頂点に対して自作の3次元フラクタルノイズ（`fbm3`、`valueNoise3`）を計算し、その値の分だけ球の半径方向にずらして「有機的な塊」の形を作る
4. 変形後の実ジオメトリから面法線を計算し、頂点ごとに平均することで滑らかな陰影用法線を得る

これは「1個だけの、しかし単なる球ではないオブジェクト」を、外部の3Dモデルファイルなしにコードだけで作る方法です。

### 3. 疑似メタリック・シェーダー
本物の環境マップ画像（HDRI）は使わず、フラグメントシェーダー内の `fakeEnv()` 関数で、反射ベクトルの向きから「上が明るく、水平線に細い光の帯がある」スタジオ照明っぽい色を数式だけで合成しています。これにフレネル項（視線とほぼ垂直な面ほど強く光る効果）を足し合わせることで、金属や樹脂のような質感を安価に表現しています。

### 4. バネ・ダンパー物理による「重さ」
```js
yawVel += (targetYaw - yaw) * STIFFNESS; // 目標との差分だけ加速
yawVel *= DAMPING;                       // 毎フレーム減衰させる
yaw += yawVel;                           // 位置を更新
```
目標角度（マウス位置から計算）に対して、現在の角度がバネのように追いかけ、摩擦(DAMPING)で徐々に収束します。`STIFFNESS`（バネの強さ）と `DAMPING`（減衰率）の2つの数値を変えるだけで、「キビキビ」から「ずっしり」まで質感を自由に調整できます。

### 5. スクロール駆動のカメラ移動
ページ本体の下に高さ500vhの透明な `#scroll-spacer` を置き、そのスクロール量から `0〜1` の進捗値を計算します。この進捗値を使って、
- カメラのZ座標を手前から奥へ移動させ、
- アクセントカラー（インディゴ→マゼンタ）を連続的に混ぜ合わせ、
- 4つのテキストパネルの表示・非表示を切り替えています。

いわゆる「スクロールジャック」ですが、実際にはページを縦にスクロールしているだけで、見た目上はカメラが3D空間の奥へ進んでいるように感じられます。

### 6. カスタムカーソル & マグネティックボタン
`initCustomCursor()` と `initMagnetic(selector, strength, radius)` という2つの独立した関数にしてあります。カーソルは目標座標に対して `lerp`（線形補間）で少し遅れて追従し、ボタンは半径 `radius` px 以内にカーソルが入ると、その方向に `strength` 倍だけ引き寄せられます。

## 使い方（コピーしてすぐ使う）

1. `index.html` をそのまま自分のプロジェクトにコピーします（外部ライブラリの読み込み・ビルド設定は一切不要です）。
2. ブラウザで直接開くだけで動作します（ローカルサーバーも不要）。
3. カスタマイズしたいときは、以下の値を変えるだけで印象が大きく変わります。
   - `createOrganicIcosphere(3, 0.16)` の第2引数 → デコボコの強さ
   - `ACCENT_A` / `ACCENT_B`（JavaScript内の配列）→ アクセントカラー
   - `STIFFNESS` / `DAMPING` → 回転の「軽さ・重さ」
   - `.panel` の `data-range="開始,終了"` → 各セクションが表示されるスクロール範囲（0〜1）
4. ボタンやリンクに `data-magnetic` 属性を付けるだけで、マグネティックカーソル効果を追加できます。
   ```html
   <a href="#" data-magnetic>Contact</a>
   ```

## 注意点・既知の制約

- WebGL2 に対応していないブラウザでは3Dオブジェクトが表示されません（`gl` が `null` になった場合のフォールバックUIは今回省略しています）。
- タッチデバイスでは、`cursor:none` によるカスタムカーソル非表示とマグネティック効果を `@media (pointer:coarse)` で無効化しています。
- 反射表現はHDRIを使わない近似（手続き的な疑似環境色）のため、本物のイメージベースドライティングほどのリアルさはありません。あくまで「軽量・依存ゼロで“それっぽさ”を出す」ための学習用の工夫です。
