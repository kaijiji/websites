## 評価されている理由・印象的だった点（検索でわかった範囲）

- CSS Design Awards *Website of the Day* およびAwwwards Honorable Mentionを受賞し、Communication Artsの *WEBPicks* にも選出されている
- 最大の見どころは、ヒーローで存在感たっぷりに回転する**クローム仕上げの3Dロゴ**が、スクロールすると**縮小しながらヘッダー左上へ吸い込まれるようにドッキングし、そのまま実際のホームリンクとして機能し続ける**という演出。装飾で終わらず実用のUIパーツに「着地」する点が高く評価されている
- ロゴの**回転速度・回転方向がスクロール速度に連動**しており(速くスクロールするほど速く回り、逆スクロールで逆回転)、「常に稼働し続ける機械」というコンセプトをインタラクションのレベルで体現している
- 3つのWebGLシーンをページ遷移とともに破綻なく調停する設計や、記事をオーバーレイドロワーで開いてスクロール位置を保つ配慮など、派手な表現の裏に手堅いエンジニアリングがある
- 「1980年代のお役所仕事・古いCRTモニター」という一貫したビジュアルコンセプトを、最新のWebGL技術で再解釈している落差が魅力

## 使われている技術・ライブラリの推測

検索結果（本文・Codrops記事の要約）から確認できた事実は次の通りです。実際のコードは見ていません。

- **Nuxt / Vue.js** — フロントエンドフレームワーク
- **GSAP + ScrollTrigger** — スクロール連動アニメーション全般を駆動
- **Lenis** — 慣性付きスムーススクロール
- **Three.js** — WebGL表現。`SVGLoader` でロゴSVGを読み込み `ExtrudeGeometry`(ベベル有効)で立体化し、`MeshPhysicalMaterial` の metalness・clearcoat を PMREM 環境ライティング下で使うことで鏡面のクローム仕上げを作っていると説明されている
- **Pinia** — 状態管理
- **Sass** — CSSフレームワークなしのスタイリング

このデモでは、Three.jsやGSAPなどのライブラリそのものは使わず、**生のWebGL(GLSL)とバニラJavaScript・CSSのみ**で、「クロームの押し出しロゴ」「スクロール速度に連動する回転」「ヒーロー→ヘッダーへのドッキング」「記事オーバーレイドロワー」という体験の核を再現しています。

## 再現コードの仕組みの解説

`index.html` 1ファイルにCSS・JavaScriptをすべてインラインで記述しています。仕組みごとに関数/コードブロックが分かれているので、必要な部分だけ他のプロジェクトにもコピーできます。

### 1. ジオメトリ生成 — 生WebGLで「＋マーク」を厚み付き押し出し（`buildPlusMarkGeometry()`）

実サイトは SVGLoader → `ExtrudeGeometry(bevelEnabled:true)` という Three.js の機能でロゴを立体化していますが、このデモは Three.js を使わないため、同じ考え方を手作業で再現しています。

1. 「＋（プラス）」の輪郭を、2D平面上の12個の点として定義する（縦棒と横棒が交差する形）
2. その12点を **Z軸方向に押し出す**（前面用コピーと背面用コピーを作り、Zをずらす）ことで厚みを持たせる
3. 前面・背面は、＋形を「上下左右の腕4枚 + 中央」という5枚の矩形（＝10枚の三角形）に分解して塗りつぶす
4. 輪郭の12辺それぞれについて、前面と背面をつなぐ側面の板(壁)を1枚ずつ張る
5. 本物のベベル(面取り)ジオメトリは作らず、**側面の各頂点の法線を「隣り合う面の法線の平均」にする**ことで、面と面の継ぎ目にハイライトがなめらかに回り込む「面取りされたような」見た目を軽量に近似しています（正確な面取りが欲しい場合はThree.jsの`ExtrudeGeometry`の`bevelThickness`/`bevelSize`を使うのが本来のやり方です）

### 2. フェイク環境マップによるクローム表現（フラグメントシェーダー内 `envColor()`）

本物のクローム表現には撮影されたHDRI画像を環境マップとして反射させますが、それを使わずに**数式だけで「それっぽい」反射環境**を作っています。

- 反射ベクトル `R = reflect(-V, N)` を計算し、その **上下方向 (`R.y`)** に応じて「暗い床 → 明るい空」のグラデーションを作る
- `R.y` がある高さに近いところだけ明るくなる帯を2本重ねることで、写真スタジオの天井にある**ソフトボックス(照明)が映り込んでいるような光の帯**を表現する
- 加えてフレネル項（法線と視線のなす角が浅いほど反射が強くなる効果）と、鏡面ハイライト(Blinn-Phong)を足し合わせることで、単なるグレーの塊がクロームらしい質感になる

### 3. スクロール速度 → 回転速度・回転方向

```js
const delta = window.scrollY - lastScrollY;
scrollVelocity = lerp(scrollVelocity, delta, 0.18); // 一次ローパスフィルタで滑らかに
spin += 0.0035 + scrollVelocity * 0.02;              // アイドル回転 + スクロール速度分
```

毎フレーム、直前とのスクロール量の差分(`delta`)を取り、線形補間(lerp)で滑らかに追従させた値を `scrollVelocity` として保持します。これを回転角に加算するだけで、「速くスクロールすると速く回り、上にスクロールを戻すと逆回転する」という挙動が作れます。

### 4. ヒーロー→ヘッダーへのドッキング演出

```js
const progress = easeInOutCubic(clamp01(sy / DOCK_DISTANCE()));
const pos   = lerp(HERO_POS,   DOCK_POS,   progress); // 3成分それぞれlerp
const scale = lerp(HERO_SCALE, DOCK_SCALE, progress);
```

スクロール量を0〜1の進捗値(`progress`)に変換し、その値でヒーロー中央の位置・大きさと、ヘッダー左上にドッキングした状態の位置・大きさを線形補間します。WebGLキャンバス自体は常時 `position:fixed` で画面全体を覆っていますが、背景は透明(`gl.clearColor(0,0,0,0)`)なので、ロゴが描かれている部分だけがヘッダーの上に浮かんで見える仕組みです。`progress` が一定値を超えたらヘッダーのDOM要素に `.docked` クラスを付け、半透明の背景やナビゲーションリンクをフェードインさせています。ドッキングしたロゴの上には透明な `#home-hit` 要素を重ね、クリックで `scrollTo({top:0})` することで「実際のホームリンクになる」動きを再現しています。

### 5. Journalのオーバーレイドロワー

記事をクリックすると、`data-*` 属性から取り出したタイトル・日付・本文を右側の固定パネルに差し込み、`transform: translateX(100%) → translateX(0)` のトランジションでスライドインさせます。ページ遷移が発生しないので、裏側の本文のスクロール位置がそのまま保たれます。

## 使い方（コピーしてすぐ使う手順）

1. `index.html` をそのまま自分のプロジェクトにコピーします（外部ライブラリ・CDN依存は一切ありません）。
2. ロゴの形を変えたい場合は `buildPlusMarkGeometry()` 内の `outline` 配列（12点の2D座標）を書き換えてください。座標が全て軸に平行な形であれば、`quads` の対応関係を調整するだけで同じ仕組みが使えます。
3. ヒーロー時とドッキング時の位置・大きさは `HERO_POS` / `HERO_SCALE` / `DOCK_POS` / `DOCK_SCALE`（`frame()` 関数の少し上）で調整できます。ヘッダーの左パディング（CSSの `header{ padding-left:92px }`）と `#home-hit` の位置も合わせて調整してください。
4. 配色は `:root` の CSS変数（`--bg` / `--ink` / `--accent` など）を書き換えるだけで一括変更できます。
5. CRT風のスキャンライン・粒子ノイズは `#crt-overlay` / `#noise-overlay` の2つの装飾レイヤーです。不要であれば削除しても他の仕組みには影響しません。
