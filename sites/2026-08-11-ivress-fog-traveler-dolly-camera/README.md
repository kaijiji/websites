## どんなサイトか

IVRESSは、大阪を拠点にICT(情報通信技術)でビジネスの進化を支える企業のブランドサイトです。サイトはまるで短編映画の冒頭シーンのように始まります。「ここには光を拒む世界がある」という趣旨の一文とともに、薄暗く霧に包まれた3D風景の中に小さな旅人のシルエットが佇み、ナレーションなしで「訪れる・世界が気づく・何かが起こる」というだけの静かな物語が進んでいきます。

技術的な見どころは、Three.jsの**WebGPURenderer**(WebGL未対応環境へは自動的にWebGLへフォールバック)を採用し、**TSL(Three.js Shading Language)**で書かれたシェーダーがWebGPU/WebGLの両バックエンドで動く点です。2026年は「WebGPUを実プロダクトへ安全に出荷できるようになった年」と言われており、IVRESSはその代表例として複数のWebGL/WebGPUコミュニティで紹介されています。

### 印象的だった点(推測を含む)

- **「光を拒む世界」というコンセプトを、暗さそのもので魅せている**点。派手な演出を足すのではなく、霧・暗闇・遠くの淡い光という「引き算」の演出で世界観を伝えている。
- 小さな人物(旅人)を画面の主役に置き、**カメラが物語の視点を持って動く**、映画のワンカットのような構成。
- 次世代レンダリング技術(WebGPU)を、体験のためではなく**あくまで物語を支える裏方**として使っている点(技術のひけらかしになっていない)。

## 使われている技術・ライブラリの推測

- **Three.js `WebGPURenderer`**(WebGL フォールバック付き)— 3Dランドスケープと旅人のレンダリングに使用と推測。
- **TSL (Three.js Shading Language)** — WebGPU/WebGLの両方にコンパイルされるシェーダー記述に使用と推測。
- おそらく **GSAP + ScrollTrigger** 相当のスクロール連動ライブラリ(カメラワークやテキストの出現タイミング制御に、多くの受賞サイトで標準的に使われる構成のため)。
- 霧・被写界深度・ブルームなどの**ポストプロセッシング**(暗い世界観の質感づくりに使われていると推測)。

## 再現デモの仕組み

`index.html` は、外部ライブラリを一切使わず **生WebGL2 API** だけで、「霧に沈んだ3Dランドスケープを、スクロールでカメラがドリー(前進)しながら旅人へ近づいていく」という表現ジャンルを再実装した学習用デモです。

### 1. 地形メッシュの生成(`createTerrain`)

- グリッド状の頂点を並べ、`fbm2`(値ノイズを複数オクターブ重ねたFractal Brownian Motion)で高さをずらして緩やかな起伏を作っています。
- 面ごとの法線を計算し、同じ頂点を共有する面の法線を加算平均することで、滑らかなシェーディングになる頂点法線を得ています。

### 2. 旅人シルエットの生成(`createTraveler` / `addBox`)

- 直方体(脚2本・胴・頭・マント)を組み合わせただけの、ごく簡単なローポリ人型です。
- `addBox`は1つの直方体につき24頂点(6面×4頂点)を独立して生成し、面ごとに正確なフラットシェーディング用法線を持たせています(Three.jsの`BoxGeometry`を使わず、頂点計算をゼロから実装)。

### 3. 霧 + リムライトのシェーダー(`SCENE_FRAG`)

- 深度(カメラからの距離)をもとに`1.0 - exp(-density * distance^2)`という指数二乗フォグの式で、遠くのオブジェクトほど背景のフォグ色に溶け込ませています。
- 旅人や地形の輪郭には、視線ベクトルと法線の角度差(フレネル項)から**リムライト**(縁だけがぼんやり光る効果)を加算し、「暗闇の中で輪郭だけがうっすら光で縁取られる」というシルエット表現を作っています。

### 4. スクロール連動のドリーカメラ(`WAYPOINTS` / `sampleWaypoints`)

- カメラの位置・注視点・フォグの濃さ・光の色を4つの「章」ごとにウェイポイントとして定義し、スクロール進捗(0〜1)に応じてその区間を線形補間しています。
- 序盤は高い位置から見下ろす**確立ショット**、終盤は旅人のすぐ近くまで寄る構成にすることで、映画のワンシーンのような視点移動を作っています。
- 生の`scrollY`をそのままカメラに使わず、`smoothProgress += (raw - smoothProgress) * 0.07`というlerp(線形補間)を毎フレーム挟むことで、カクつかない滑らかなカメラワークになります。

### 5. 常にカメラを向く光源ビルボード(`GLOW_VERT`)

- 遠くの「灯り」を1枚の板ポリゴンで表現しつつ、頂点シェーダー内で`uRight`・`uUp`(カメラの右方向・上方向ベクトル)を使ってその場で板の頂点を組み立てることで、**常にカメラのほうを向くビルボード**にしています。
- フラグメントシェーダーでは中心からの距離をべき乗で減衰させ、`gl.blendFunc(SRC_ALPHA, ONE)`の加算合成でにじむような光のグロー効果を作っています。

### 6. 浮遊する塵(`DUST_VERT`)

- 140個の点(`gl.POINTS`)を、頂点シェーダー内で`mod()`を使って一定の高さ範囲を上へループさせ続けることで、CPU側からバッファを毎フレーム書き換えることなく浮遊させています。
- 距離に応じて点のサイズと不透明度を変化させ、光源の色と同じ色で加算合成することで、光を受けてかすかに見える塵のような質感にしています。

### 7. 縦書きテキストの章立て演出

- `writing-mode:vertical-rl`で縦書きにした4つの`<section class="chapter">`を用意し、スクロール位置(`data-range`属性)に応じて`is-visible`クラスをトグルしています。
- 左右交互に配置することで、旅の場面転換ごとに視線の置き場所が変わる演出にしています。

### 8. フィルムグレイン(`initGrain`)

- 96×96のCanvasにランダムノイズを描き込み、`createPattern`でタイル状に敷き詰めたものを`mix-blend-mode:overlay`で薄く重ね、一定間隔で再描画してちらつかせることで、フィルム調の粒状感を出しています。

## 使い方(自分のプロジェクトへの組み込み方)

1. `index.html`をそのままコピーして開けば、単体で動作します(外部ライブラリ・画像ファイル一切不要)。
2. 章の数やカメラワークを変えたい場合は、`WAYPOINTS`配列の`eye`(カメラ位置)・`look`(注視点)・`fogDensity`・`fogColor`・`lightColor`を編集してください。要素数は自由に増減できます。

   ```js
   const WAYPOINTS = [
     { t:0.00, eye:[x,y,z], look:[x,y,z], fogDensity:2.6, fogColor:[r,g,b], lightColor:[r,g,b], amb:0.1 },
     // ... 好きな数だけ追加
   ];
   ```

3. 自分の3Dオブジェクトを置きたい場合は、`createTraveler()`を独自の`addBox`呼び出しの組み合わせに置き換えるか、既存の頂点/法線/インデックス配列(`positions` / `normals` / `indices`)を差し替えれば`makeVAO()`にそのまま渡せます。
4. テキスト部分は`.chapter[data-range]`の`data-range`(スクロール進捗の開始・終了)を調整するだけで、好きなタイミングで表示を切り替えられます。横書きにしたい場合は`writing-mode:vertical-rl`のCSSを外してください。

## 注意

- 本デモはIVRESSのブランドや実際のクリエイティブそのものを模倣・転載する意図はなく、あくまで「霧のフォグシェーダー」「リムライトによるシルエット表現」「スクロール連動のドリーカメラ」という**表現技法の学習**を目的とした独自実装です。
- 実際のIVRESSサイトはThree.jsのWebGPURenderer(TSLシェーダー)を用いていると考えられますが、本デモは互換性を優先し、広くサポートされているWebGL2の生APIで同様の表現ジャンルを再現しています。
- 文章・配色・3D形状はすべて学習用に独自制作したものであり、実際のIVRESSのサイトとは異なります。
