## 評価されている理由・印象的だった点

検索結果から確認できた紹介記事の要約によると、Hubtownは「たった1つの3Dオブジェクトに作り込みを集中させることで、複雑なシーンを作らずに強い印象を残す」演出が評価されています。

- 暗く落ち着いたトーンの中に、光る3Dモノリスが反射する床の上に浮かんでいる、というシンプルながら映画的なヒーロービジュアル
- カーソルを動かすとオブジェクトのジオメトリやライティングの見え方が変化する「マウスでリベール(明らかに)する」インタラクション
- 40年分の企業の歩みを、まず没入感のあるスクロールストーリーとして見せたあと、都市(ムンバイ)の物件を探索できるインタラクティブマップへとシームレスに切り替える構成
- 「フルの3Dシーンを作り込む」のではなく「1つのオブジェクトに重さ・慣性・光の反応を丁寧に持たせる」という、実装コストと視覚的インパクトのバランスが評価軸として紹介されている

## 使われている技術・ライブラリの推測

検索結果の要約(Awwwardsの受賞ページ情報、および同種のThree.js作品を紹介する記事の要約)から、以下の技術的特徴が使われていると推測しました。

- **Three.js(WebGL)** — 単一のヒーロー用3Dオブジェクトを描画し、慣性のある回転・ライティング・反射を組み合わせている、いわゆる「1つのオブジェクトに重さを持たせる」Three.js表現の代表例として紹介されています
- **GSAP** — スクロール位置に応じたカメラワークやテキストの出現タイミング制御に使われる定番ライブラリ(Awwwardsのタグにも記載あり)
- **カーソル追従のライティング** — マウス座標を光源の位置(または明るさ)にマッピングし、触れた場所だけがハイライトされる「リベール」インタラクション
- **擬似的な床反射** — 「暗く反射する地面」の質感は、本格的なレンダーターゲット式の鏡面反射(Three.jsの `Reflector` のような仕組み)、あるいはより軽量な反転コピー+ぼかしのテクニックで作られていると推測されます

このデモでは、GSAPを使わず**Three.js(WebGLの描画部分)のみ**を外部ライブラリとして使い、スクロール連動やテキストの出現は依存ゼロのバニラJavaScript(`scroll`イベント + `IntersectionObserver`)で実装しています。ライブラリなしでも「スクロール量→カメラの角度」のような処理は数十行で書けることを実感できるようにするためです。

## 再現コードの仕組みの解説

`index.html` 1ファイルに CSS・JavaScript をすべてインラインで記述し、3D描画のみ `vendor/three.module.min.js` を読み込んでいます。実装は大きく4つの仕組みに分かれており、それぞれ他プロジェクトにもそのままコピーできます。

### 1. `createMonolithScene(canvas)` — 1つのオブジェクトに重さと光を宿す

`<canvas>` 要素を渡すだけで使い回せる関数としてまとめています。ポイントは次の3つです。

- **少ないポリゴンで表情を出す形** — `THREE.IcosahedronGeometry(1.5, 0)` (detail=0の正二十面体)を縦に引き伸ばし、`flatShading: true` にしています。detailを上げず、面を平らなまま残すことで、光が当たった面とそうでない面のコントラストがはっきり出て、少ない頂点数でも「結晶(モノリス)」らしい存在感が出ます。
- **慣性(重さ)のある回転** — マウス座標から求めた「目標の回転角」に対して、現在の回転角を毎フレーム少しずつ近づけています(`rotY += (rotYTarget - rotY) * damp`)。目標値に瞬時に到達させず、指数関数的に追いつかせることで、物理シミュレーションをしなくても「重さがあって、少し遅れて動く」感触が生まれます。これはドラッグ操作やパララックスなど、あらゆる「追従アニメーション」に応用できる汎用テクニックです。
- **カーソル追従のリベールライト** — `THREE.PointLight` を1つ用意し、マウス座標(-1〜1に正規化した値)を3D空間のXY位置に直接マッピングして追従させています。マウスがキャンバス上にある間だけ光の強さを上げることで、「触れた場所だけ明るくなる」体験になります。本格的にやるなら `Raycaster` でオブジェクト表面上の実際の交点を求める方法もありますが、このデモではシンプルな座標マッピングだけでも十分にそれらしい効果が出ることを示しています。

### 2. 擬似的な床反射(fake reflection)

本物の鏡面反射(レンダーターゲットに反転カメラでシーンを描画し、その結果を床のテクスチャとして貼る手法)は実装がやや複雑になるため、このデモでは**モノリスをそのまま複製し、Y軸方向に反転して床の下に配置、半透明にして霧(`THREE.FogExp2`)に沈める**という軽量な方法で同じ雰囲気を再現しています。

```js
const reflection = monolith.clone();
reflection.material = monolithMat.clone();
reflection.material.transparent = true;
reflection.material.opacity = 0.25;
reflection.scale.y *= -1;          // Y軸で反転
reflection.position.y = -1.0;      // 床を挟んで対称の位置へ
```

本物の反射が必要なプロダクションサイトを作る場合は、Three.jsの `Reflector` (公式アドオンや各種チュートリアルで紹介されている、レンダーターゲット+反転カメラの実装)を調べてみてください。

### 3. スクロール連動のカメラワーク(GSAP不使用)

`#scene-spacer` という高さ340vhの透明な要素を用意し、その要素がビューポートに対してどれだけスクロールされたかを0〜1の値(`scrollProgress`)として毎フレーム計算しています。

```js
const rect = spacer.getBoundingClientRect();
const total = rect.height - window.innerHeight;
const progress = total > 0 ? (-rect.top) / total : 0;
```

この値を使って、カメラをモノリスの周りで半周させながら少しずつ寄せています(`Math.sin`/`Math.cos` で円軌道の座標を計算し、`camera.lookAt()` で常にモノリスを見続けさせる)。GSAPのScrollTriggerが内部でやっていることも、突き詰めると「スクロール位置を0〜1の値に変換し、その値で好きなプロパティを補間する」という処理なので、ライブラリなしでも十分再現できます。

また、`IntersectionObserver` で `#scene-spacer` が画面外に出たタイミングを検知し、3Dの描画ループ(`requestAnimationFrame`)自体を止めることで、マップセクションを見ている間の無駄なGPU負荷を抑えています。

### 4. `initScrollReveal()` / `initExploreMap()` — テキストと探索UIの出現演出

- `initScrollReveal()` は `data-reveal` 属性を付けた要素を `IntersectionObserver` で監視し、画面に入ったら `is-visible` クラスを付与するだけの汎用関数です。あとはCSS側の `transition` で「ふわっと下から出てくる」動きを表現しています。
- `initExploreMap()` は、ストーリー演出のあとに現れる「探索できるグリッドUI」への切り替えを表現するためのダミーデータです。実在の地図画像・位置情報・物件データは一切使わず、CSSのグリッド背景上にランダムでない固定座標のダミーピンを配置し、`transitionDelay` をずらすことで出現時に流れるようなスタガー(段差)アニメーションを作っています。

## 使い方(コピーしてすぐ使う手順)

1. `index.html` と `vendor/three.module.min.js` を、自分のプロジェクトの好きな場所にそのままコピーします(フォルダ構成を保ってください)。
2. 見出し・本文・配色(`:root` の CSS変数)を自分のプロジェクト用に書き換えます。
3. 3Dオブジェクトの形を変えたい場合は `createMonolithScene()` 内の `monolithGeo` の生成部分(`THREE.IcosahedronGeometry` など)を、好きなThree.jsのジオメトリに差し替えるだけで、慣性・ライティング・反射・スクロール連動カメラの仕組みはそのまま使えます。
4. `initExploreMap()` の `points` 配列を、実際のデータ(店舗一覧・拠点一覧など)に差し替えれば、そのまま「ストーリー→探索UI」という構成の別サイトにも転用できます。
5. `file://` で直接開くとブラウザによっては `type="importmap"` や `type="module"` が制限される場合があるため、`npx serve` や `python3 -m http.server` などの簡易サーバー経由で開くことをおすすめします。

`vendor/three.module.min.js` は、npm公式レジストリで配布されているMITライセンスのオープンソースライブラリ(Three.js)をそのまま同梱したものです。対象サイトの著作物ではなく、誰でも自由に利用できるライブラリなので、自分のプロジェクトでもそのまま使えます。バージョンを更新したい場合は [three.js](https://www.npmjs.com/package/three) のnpmパッケージを取得し直してください。
