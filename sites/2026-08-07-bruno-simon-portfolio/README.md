# 🚗 車を運転して周れる3Dポートフォリオ — 再現デモ

## 参照元サイト

- **サイト名**: Bruno Simon — Portfolio
- **URL**: https://bruno-simon.com
- **受賞歴**: Awwwards *Site of the Year*、*Developer Award*、CSS Design Awards *Website of the Year* など多数受賞。400,000人以上が訪問した、Webデザイン業界で非常に有名なポートフォリオサイトです。

> 本フォルダのコードは学習目的のオリジナル実装です。上記サイトの実際のソースコード（HTML/CSS/JS）は一切使用・複製していません。観察した「表現の仕組み」を自分の理解に基づいてゼロから書き直しています。

## 評価されている理由・印象的だった点

Bruno Simon 氏のポートフォリオは、「スクロールして作品を見る」という一般的なポートフォリオサイトの常識を覆し、**3D空間の中でトイカーを運転しながら作品を発見していく**という体験を提供したことで高く評価されました。

- ページ遷移やスクロールバーが存在せず、移動そのものがナビゲーションになっている
- 物理演算によってタイヤが弾んだり、障害物にぶつかって箱が転がったりと「本物の乗り物」に近い触感がある
- 車で作品(タイヤのブランコ、砂場、看板など)に近づくと、その場でプロジェクト情報が開く
- 遊び心があるのに、きちんと開発者としてのスキル(WebGL・物理演算の実装力)を証明する内容になっている

## 使われている技術・ライブラリの推測

公開情報や技術記事から、以下の構成が使われていると推測されています。

- **[Three.js](https://threejs.org/)** — WebGLベースの3Dレンダリングライブラリ。シーン・カメラ・ライティング・メッシュの描画を担当。
- **[Cannon.js](https://schteppe.github.io/cannon.js/)（もしくはそのフォークである cannon-es）** — JavaScript製の3D物理演算エンジン。車の挙動、サスペンション、他オブジェクトとの衝突を計算。
- 車の運転ロジックには物理エンジンが提供する `RaycastVehicle`（レイキャスト式の車両シミュレーション）が使われていると考えられます。各ホイールから地面に向かってレイ(光線)を飛ばし、サスペンションの伸縮を計算する仕組みです。

このデモでも同じ組み合わせ（Three.js + cannon-es の `RaycastVehicle`）を採用し、仕組みを再現しています。

## 再現コードの仕組みの解説

`index.html` 1ファイルに、CSS・JavaScript(ES Modules)をすべてインラインで記述しています。処理は大きく分けて次の8ステップです。

1. **Three.js の基本セットアップ** — シーン・カメラ・レンダラーを作成し、影付きのライトを配置します。
2. **cannon-es の物理ワールド** — 重力を持つ `CANNON.World` を作成します。地面用・タイヤ用のマテリアルを分けて摩擦を設定しているのがポイントです。
3. **地面と障害物の配置** — `addBox()` という自作のヘルパー関数で、「Three.js のメッシュ」と「cannon-es の物理ボディ」をセットで作成しています。見た目と物理判定を1つの関数にまとめることで、コースを増やしたいときはこの関数を呼ぶだけで済むようになっています。
4. **看板（プロジェクト紹介パネル）** — Canvas に文字を描いてテクスチャ化し、`THREE.Sprite` に貼り付けています。3Dモデルを用意しなくても手軽にテキスト付きの目印を3D空間に置けるテクニックです。
5. **車体の組み立て** — `CANNON.RaycastVehicle` にシャシー(車体)と4つのホイール情報を登録します。ホイールの「サスペンションの硬さ」「減衰」「摩擦」などのパラメータを調整すると、車の乗り心地が大きく変わります。
6. **操作入力** — キーボード(矢印キー / WASD)とスマートフォン用のタッチボタンの両方に対応しています。押されているキーの状態を `input` オブジェクトに保持し、毎フレーム参照する設計です。
7. **プロジェクトパネルの表示判定** — 毎フレーム、車と各看板との距離を計算し、一定距離より近づいたら画面下にパネルを表示します。「3D空間上の近接判定でUIを出し分ける」という、ゲームではよく使われるが Web サイトではあまり見ない演出です。
8. **メインループ** — `requestAnimationFrame` の中で物理演算を1ステップ進め (`world.step`)、その結果をThree.jsのメッシュ位置に反映します。物理エンジンと描画エンジンの2つの世界を、毎フレーム同期させ続けるのがこの手の表現の心臓部です。

### つまずきやすいポイント（実装時に直面した問題と対策）

- **障害物は必ず地面と接続する**: 物理ボディが宙に浮いた「壁」になっていると、車が高速で突っ込んだ瞬間に激しく弾き飛ばされます。ランプ(斜面)は地面と隙間なくつながるように角度・位置を計算しています。
- **速度のクランプ（セーフティネット）**: 何かにぶつかった拍子に物理演算が不安定になり、車が異常な速度で吹き飛ぶ「physics explosion」を防ぐため、毎フレーム速度の上限をチェックしています。自作の物理ゲームでも役立つ、シンプルながら効果的なテクニックです。

## 使い方（コピーしてすぐ使う手順）

1. このフォルダ（`index.html` と `vendor/` フォルダ）をまるごと自分のプロジェクトにコピーします。
2. ローカルサーバーで配信して開きます（`file://` で直接開くと ES Modules の読み込みでエラーになる場合があります）。

   ```bash
   cd sites/2026-08-07-bruno-simon-portfolio
   python3 -m http.server 8080
   # ブラウザで http://localhost:8080 を開く
   ```

3. 矢印キーまたは `WASD` で運転できます。スペースキーはブレーキです。スマートフォンでは自動的に画面下に仮想ボタンが表示されます。
4. 看板に近づくと画面下にプロジェクト情報パネルが表示されます。`projects` 配列（`index.html` 内）を書き換えれば、自分の作品紹介に差し替えられます。
5. コースを増やしたい場合は `addBox({ size, position, color, mass, rotationX, rotationY })` を呼ぶだけで、見た目と物理判定の両方を持つオブジェクトを追加できます。

### vendor フォルダについて

`vendor/three.module.min.js` と `vendor/cannon-es.js` は、npm 公式レジストリで配布されている MIT ライセンスのオープンソースライブラリ（Three.js / cannon-es）をそのまま同梱したものです。対象サイトの著作物ではなく、誰でも自由に利用できるライブラリなので、自分のプロジェクトでもそのまま使えます。バージョンを更新したい場合は [three.js](https://www.npmjs.com/package/three) と [cannon-es](https://www.npmjs.com/package/cannon-es) の npm パッケージを取得し直してください。
