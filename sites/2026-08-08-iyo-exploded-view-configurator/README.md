## 評価されている理由・印象的だった点

検索結果から確認できた紹介記事の要約によると、iyOは「単なるポートフォリオ的な演出ではなく、実際に商品を売るための3D表現」として評価されているECサイトです。

- ホームページ全体を覆う、100万点規模ともいわれる密度の高いパーティクルフィールドのヒーロー演出
- 商品ページでは静的なスペック表の代わりに、**スクロールに連動してハードウェアの内部構造がZ軸方向に分解されていく「エクスプローデッドビュー(分解図)」**でパーツを1つずつ見せる構成
- パーツにカーソルを合わせる(または分解が進む)と、そのパーツが手前に浮き上がり、ラベル付きのホットスポットが表示される
- あらかじめ焼き込んだテクスチャの切り替えではなく、**マテリアルのパラメータ(色・金属質感)をその場で変更するリアルタイム・コンフィギュレーター**で、色や仕上げ(マット/メタリック/グロッシー)を選べる
- 「1つの3Dオブジェクトを作り込む」演出が多い中で、iyOは**分解 → 説明 → 購入前のカスタマイズ**という一連のプロダクト理解の導線そのものを3D表現で組み立てている点がユニークです

## 使われている技術・ライブラリの推測

検索結果の要約(Awwwardsの受賞ページ情報、および類似の3Dプロダクトコンフィギュレーターを紹介する記事の要約)から、以下の技術的特徴が使われていると推測しました。

- **Three.js(WebGL)** — パーティクルフィールド・3Dモデルの描画・マテリアルのリアルタイム変更のいずれにも使われていると推測されます
- **カスタムGPUパーティクルシステム** — ヒーローの高密度パーティクル表現は、頂点シェーダーで大量の点を動かすGPUベースの実装と推測されます
- **スクロール連動アニメーション(GSAP ScrollTrigger 等)** — スクロール位置を0〜1の進捗値に変換し、3Dオブジェクトの位置・カメラアングルをその進捗にひも付けている可能性が高いです
- **マテリアルの動的書き換え** — 商品の色・質感オプションは、テクスチャの貼り替えではなく `material.color` や `metalness` / `roughness` パラメータを直接更新するリアルタイム処理と推測されます

このデモでは、外部ライブラリとして**Three.js(WebGLの描画部分)のみ**を `vendor/three.module.min.js` としてローカルに同梱し(MITライセンスのオープンソースライブラリなので同梱可能です。iyO自体のコードではありません)、スクロール連動やUI操作は依存ゼロのバニラJavaScriptで実装しています。GSAPのような専用ライブラリがなくても「スクロール量→3Dオブジェクトの状態」を数十行のコードで表現できることを実感できるようにするためです。

## 再現コードの仕組みの解説

`index.html` 1ファイルに CSS・JavaScript をすべてインラインで記述し、3D描画のみ `vendor/three.module.min.js` を読み込んでいます。実装は大きく3つの仕組みに分かれており、それぞれ他プロジェクトにもそのままコピーできる関数として `createParticleHero()` / `createExplodedView()` / `createConfigurator()` にまとめています。

### 1. `createParticleHero(canvas)` — 密度の高いパーティクルフィールド

- `THREE.BufferGeometry` に9,000点の頂点座標を持たせ、`THREE.Points` + `AdditiveBlending`(加算合成)で描画しています。加算合成にすることで、点が重なる場所ほど明るく発光して見え、少ない点数でも密度感のある霧のような塊に見えます。
- 各点はまず球殻状(半径をランダムに散らした球の表面)に配置し、毎フレーム `Math.sin` / `Math.cos` を位相をずらして加算することで、Perlinノイズのような有機的な揺らぎを疑似的に再現しています(本格的な実装では `simplex-noise` などのノイズ関数を使うとより自然になります)。
- マウス座標をカメラ位置にごくわずかに反映させることで、視差(パララックス)による奥行き感を出しています。

```js
// ノイズライブラリなしで「有機的なゆらぎ」を作る最小構成
const wob = Math.sin(t * 1.6 + i * 0.015) * 0.06;
pos[i * 3] = baseX + wob;
```

### 2. `createExplodedView(canvas)` — スクロール連動のエクスプローデッドビュー

- プロダクトを「シェル・ドライバー・基板・バッテリー・イヤーチップ」の5パーツに分解したダミーの3Dモデルを、`CapsuleGeometry` / `CylinderGeometry` / `BoxGeometry` / `ConeGeometry` の組み合わせだけで構築しています。実務では実際の3DモデルをGLTF等で読み込む部分に差し替えられます。
- 各パーツに「組み立て済みの位置(`assembledY`)」と「完全に分解された位置(`explodedY`)」の2つの目標値を持たせておき、`setProgress(p)` が呼ばれるたびに `THREE.MathUtils.lerp(assembledY, explodedY, p)` で現在位置を補間します。**progress(0〜1)という1つの数値を渡すだけで、全パーツの分解度合いとカメラの回転、見出しテキスト、ホットスポットの表示/非表示がすべて同期して切り替わる**のがポイントです。
- スクロール連動は、高さ420vhの透明な `#explode-spacer` を用意し、`position: sticky` にした `#explode-stage` をその中に固定表示させることで、「スクロールしている間だけ画面に固定されたキャンバスの中でアニメーションが進む」という定番のピン留めスクロール手法をライブラリなしで実装しています。

```js
function onScroll() {
  const rect = spacer.getBoundingClientRect();
  const progress = Math.min(1, Math.max(0, -rect.top / (rect.height - innerHeight)));
  explodedView.setProgress(progress); // ここだけで全部同期する
}
```

- ホットスポットのラベル(HTML要素)は、パーツの3D座標を `Vector3.project(camera)` でスクリーン座標に変換し、その座標に `left` / `top` を毎フレーム合わせることで「3Dオブジェクトに追従するDOMラベル」を実現しています。Three.js初心者がよくつまずく「3D空間の位置に2DのUIを重ねたい」という要求に対する、最もシンプルな解法です。

### 3. `createConfigurator(canvas)` — マテリアルのリアルタイム切り替え

- ドラッグで回転できる商品モデルを1つ用意し、`MeshStandardMaterial` を1つだけ持たせています。カラースウォッチをクリックすると `material.color.set(hex)`、フィニッシュボタンを押すと `material.metalness` / `material.roughness` を書き換えるだけで、テクスチャの再読み込みなしに見た目がその場で変わります。
- ドラッグ操作は「目標角度(`rotYTarget`)」に対して現在角度を毎フレーム少しずつ近づける(`rotY += (rotYTarget - rotY) * 0.12`)、慣性のある回転にしており、指を離しても自動でゆっくり回り続けます。

## 使い方(コピーしてすぐ使う手順)

1. `index.html` と `vendor/three.module.min.js` を自分のプロジェクトにそのままコピーします(`vendor` フォルダの相対位置を保ってください)。
2. 3つの関数はそれぞれ独立しているので、必要な演出だけを抜き出して使えます。
   - パーティクルヒーローだけ欲しい → `createParticleHero(canvas)` を呼ぶだけでOKです。
   - 自社製品の分解図を作りたい → `createExplodedView()` 内の `makePart(...)` の行を、自社の3Dモデル(またはプリミティブ形状)に差し替えてください。`assembledY` / `explodedY` の2値を変えるだけでレイアウトを調整できます。
   - 商品ページに色・質感選択をつけたい → `createConfigurator()` の `COLORS` 配列と `.finish-btn` のHTMLを書き換えるだけで、自社商品のカラーバリエーションに対応できます。
3. ローカルで確認する場合は `index.html` のあるフォルダで簡易サーバーを立ててください(`type="module"` の `import` を使っているため、`file://` で直接開くとブラウザによってはCORSエラーになります)。

```bash
npx serve .
# または
python3 -m http.server 8000
```

4. ブラウザで開いたら、下にスクロールして分解ビューを確認し、最後のセクションでカラー/フィニッシュを切り替えてみてください。
