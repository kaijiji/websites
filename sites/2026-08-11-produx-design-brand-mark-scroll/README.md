## 再現コードの仕組みの解説

`index.html` 1ファイルにCSS・JavaScriptをすべてインラインで記述しています。5つの仕組みはそれぞれ独立した関数/コードブロックになっており、他のプロジェクトにもコピーして使えます。

### 1. WebGLヒーロー: 「呼吸するブランドマーク」（レイマーチング）

`initBrandMarkWebGL('gl-canvas')` という1関数にまとまっています。

- Three.jsのようなポリゴンメッシュを使わず、**レイマーチング(Signed Distance Field / SDF)** という手法で抽象的な塊を描いています。フラグメントシェーダーの中で「その点が塊の表面からどれだけ離れているか」を計算する関数 `map(p)` を書き、カメラから伸ばした光線(レイ)を少しずつ前進させて表面に当たるまで進める、という原理です。
- 塊は4つの球(メタボール)を `smin`(smooth minimum)関数で滑らかに融合させたもので、各球の中心が `sin`/`cos` で軌道運動し、半径も揺れることで、外部の物理エンジンなしに「呼吸している」ような有機的な動きになります。
- マウス位置をレイマーチ用カメラの回転角(`uMouse`)に渡すことで、カーソルを動かすと塊がゆっくり追従して回転する、パララックスのような視点効果を出しています。

### 2. 慣性スムーススクロール（Lenis / GSAP ScrollSmoother風）

```
const smooth = { current:0, target:0 };
function tickScroll(){
  smooth.target = window.scrollY;
  smooth.current += (smooth.target - smooth.current) * 0.09;
  content.style.transform = `translate3d(0, ${-smooth.current}px, 0)`;
}
```

- ブラウザ本来のスクロール(`window.scrollY`)を「目標値」として毎フレーム取得し、実際に表示に使う値(`smooth.current`)をその目標値へ少しずつ(9%ずつ)近づけていきます。これにより、指を止めてもすぐには止まらない「重みのある」慣性スクロールになります。
- スクロールバー自体は空の`#scroll-spacer`(本来の高さを持つダミー要素)に持たせておき、実際に見えるコンテンツ`#scroll-content`は`position:fixed`にして`transform`で動かします。ネイティブスクロールの挙動(ホイール・タッチ・キーボード操作)をブラウザに任せられるので、アクセシビリティを大きく損なわずに慣性を追加できます。

### 3. ピン留めスクロールストーリーテリング（GSAP ScrollTrigger風）

- ステートメント文(`We build brand identities for companies...`)を単語ごとに`<span class="word">`で分割しておきます。
- 文書内には`.pin-spacer`という高さ280vhの「空の予約席」を置き、スクロール量を確保します。
- 実際に表示されるテキスト(`.pin-fixed`)は、**あえて`#scroll-content`の外(bodyの直下)に配置**しています。これは、CSSの仕様上「`transform`を持つ祖先の内側にある`position:fixed`要素は、その祖先を基準に固定される」という挙動があるため、真にビューポート基準で固定表示したい要素は、transformで動かしているコンテナの外に置く必要があるからです（このバグにハマったので、同じ実装をする方への注意点として明記します)。
- 毎フレーム、`.pin-spacer`の位置とスクロール量から進行度(0〜1)を計算し、その進行度に応じて先頭から何単語目まで点灯させるかを決めています。進行度が0〜1の範囲にある間だけテキストを画面に表示し、それ以外では非表示にすることで、「スクロールが特定の区間に入ると文章が現れて単語が順番に点灯し、区間を抜けると消えて次のセクションへ進む」というピン留め演出を、GSAPなしで再現しています。

### 4. マグネティックボタン

```
el.addEventListener('mousemove', e=>{
  const dx = e.clientX - centerX, dy = e.clientY - centerY;
  el.style.transform = `translate(${dx*0.4}px, ${dy*0.4}px)`;
});
```
`class="magnetic"`をつけた要素は、その要素の内側でマウスが動くたびに、中心からのズレの40%だけ要素自身が引き寄せられるように移動します。マウスが離れると`translate(0,0)`に戻ります。

### 5. カスタムカーソル

画面中央に固定された小さな丸を、`mousemove`で取得した座標へ毎フレームlerp(線形補間)で追従させています。`data-cursor="hover"`が付いた要素にマウスが乗ると、CSSクラス`.hover`が付いてカーソルが大きなリングに変化します。

## 使い方（コピーしてすぐ使う手順）

1. `index.html`をそのままブラウザで開くだけで動作します（外部ライブラリ・ビルド不要）。
2. 自分のプロジェクトに個別の機能だけ移植したい場合は、以下の単位でコピーしてください。
   - **WebGLヒーロー**: `<canvas id="gl-canvas">`と`initBrandMarkWebGL()`関数、および対応するCSS(`#gl-canvas`)をコピーし、任意のセクションに配置して`initBrandMarkWebGL('gl-canvas')`を呼ぶだけ。
   - **慣性スムーススクロール**: `#scroll-spacer` / `#scroll-content`のHTML構造とCSS、`resizeSpacer()` / `tickScroll()`関数をコピー。ページ全体のコンテンツを`#scroll-content`の中に入れてください。
   - **ピン留めテキスト**: `.pin-spacer`(高さの確保)と`.pin-fixed`(実際に表示される要素、**必ず`#scroll-content`の外**に置く)のペア、および`tickPin()`関数をコピー。単語を`<span class="word">`で区切ったテキストを`.pin-fixed`内に用意してください。
   - **マグネティックボタン / カスタムカーソル**: それぞれ独立した即時実行関数(IIFE)になっているので、そのままコピーし、対象要素に`class="magnetic"`または`data-cursor="hover"`を付けてください。
3. 配色(`:root`のCSS変数 `--ink` / `--ecru` / `--accent`)を書き換えれば、自分のブランドカラーに合わせて見た目を調整できます。
