# CRYSTAL HOVER — 3Dホバープレビュー & 慣性スムーススクロール 再現デモ

## 参照元サイト

- **サイト名**: Noomo Showcase(Noomo Agency)
- **URL**: https://showcase.noomoagency.com/
- **受賞歴**: Awwwards *Site of the Day*(スコア 7.34/10)。Noomo Agencyにとって10回目のSite of the Day受賞で、Animation・Scrolling・Data Visualization・3D・Interaction Design・WebGLなどのカテゴリで評価されています。通常のショーリール動画の代わりに、Salesforce・AMD・Coinbase・Red Bullなど大手ブランド向けに手掛けた没入型3D/モーション制作の実績を、サイト自体の体験として見せる「エージェンシーのポートフォリオ兼ショーケース」です。

> **本フォルダのコードは学習目的のオリジナル実装です。** 参照元サイトの実際のソースコード(HTML/CSS/JS)・画像・映像・テキストコピー・クライアント名は一切取得・参照・複製していません。また、このセッションのネットワーク環境では `noomoagency.com` 本体および `awwwards.com` への直接アクセスがネットワークポリシーでブロックされていたため、実サイトを直接閲覧してはいません。検索結果に表示されたAwwwardsの受賞ページ情報(配色コード・カテゴリ・使用技術スタック・スコア・受賞歴)や、それを紹介する記事の要約だけを手がかりに、見た目・文言・コードすべてをゼロから独自に設計・実装しています。プロジェクト名やクライアント名はすべて架空のダミーです。

## 評価されている理由・印象的だった点

検索結果から確認できた情報によると、Noomo Showcaseは「エージェンシーの実力そのものを、サイトの体験として証明する」という一貫したコンセプトが評価されています。

- ほぼ黒に近いダークネイビー(`#020411`)と電光のようなブルー(`#0004EB`)という、コントラストの強い2色構成。3D/WebGLのグロー表現が映えるベースになっている
- プロジェクト一覧にカーソルを重ねると、3D(「3Dクリスタル」と呼べるような立体オブジェクト)のプレビューがカーソルに追従して現れる「Project Hover」という仕組みが、Awwwardsのインスピレーション事例として個別に取り上げられるほど印象的
- Animation・Scrolling・Data Visualization・3D・Interaction Design・WebGLという幅広いカテゴリで評価されており、単発の演出ではなく「動きの設計」全体が評価対象になっている
- グラスモーフィズム(半透明・ぼかし)なカードのスクロール出現演出など、細部のマイクロインタラクションも作り込まれている

## 使われている技術・ライブラリの推測

検索結果(Awwwardsの受賞ページ情報の要約)から、以下の技術スタックが使われていることが確認できました。

- **GSAP**(ScrollTrigger / ScrollSmoother / SplitText) — スクロール連動アニメーション、慣性のあるスムーススクロール、テキストの分割アニメーションに使われる定番ライブラリ構成
- **Three.js / WebGL** — 3Dオブジェクトの描画に使用
- **Vue** — サイトのUI構築フレームワークとして使用

このデモでは、GSAPやThree.jsといった外部ライブラリを一切使わず、**依存ゼロのバニラJavaScript**で「同じ体験の仕組み」を再現しています。GSAP ScrollSmootherが行っている「スクロールに慣性を持たせる」処理や、SplitTextが行っている「テキストを分割してアニメーションさせる」処理、Three.jsが行っている「3D座標を回転・投影して2Dに描画する」処理を、それぞれ自分で書いた小さな関数に分解しました。ライブラリの中身がブラックボックスに見える人ほど、「実は数十行の数学とDOM操作でできている」という感覚をつかめるように意識しています。

## 再現コードの仕組みの解説

`index.html` 1ファイルに CSS・JavaScript をすべてインラインで記述しています。実装は、それぞれ独立して他プロジェクトにもコピーできる小さな関数の集まりとして書かれています。

1. **`initCustomCursor()` — 二層構造のカスタムカーソル**
   小さな「ドット」はマウス座標にそのまま追従させ、外側の「リング」は `位置 += (目標位置 - 現在位置) * 係数` という線形補間(lerp)で少し遅れて追いかけさせています。この「速いドット・遅いリング」の速度差が、独特の残像感・高級感のあるカーソルを生んでいます。リンクやボタンにホバーするとリングだけが拡大します。

2. **`initSmoothScroll()` — ホイール入力を積み立てて滑らかに動かす慣性スクロール**
   ホイールイベントの `deltaY` を毎回そのまま反映するのではなく、「目標スクロール位置(target)」に積み立てておき、`requestAnimationFrame` ループの中で `現在位置 += (target - 現在位置) * lerp係数` を毎フレーム計算して `window.scrollTo()` に渡します。目標値に十分近づいたらループを止め、通常のスクロール(アンカーリンク・キーボード・スクロールバードラッグ)に制御を返す設計にしています。
   実装時、最初は `position: fixed` にしたコンテンツをtransformで動かす方式(Lenisなどでよく見る実装)を試しましたが、`getBoundingClientRect()` や `scrollIntoView()` の挙動がズレるバグを実際に踏んだため、要素を通常の文書フローに置いたまま `window.scrollTo()` で本物のスクロール位置自体を動かす、より安全な方式に書き直しています(詳細は後述)。

3. **`createIcosahedron()` / `rotatePoint()` / `drawCrystal()` — 外部ライブラリなしの3Dワイヤーフレーム**
   正二十面体(icosahedron)の12個の頂点座標を、黄金比 `φ = (1+√5)/2` を使った標準的な数式で定義します。20枚の三角形面のリストから頂点ペアを重複なく取り出すことでエッジ(辺)の一覧を作り、それぞれの頂点をX軸→Y軸の順に回転させたあと、簡易的な透視投影(`拡大率 = スケール ÷ (カメラ距離 + Z座標)`)で2D平面に変換して`<canvas>`に線を描いています。Three.jsのようなライブラリが内部でやっていることを、行列ライブラリなしで手計算しているイメージです。

4. **`initProjectHoverCrystal()` — プロジェクト一覧のカーソル追従3Dプレビュー(Project Hoverの再現)**
   プロジェクト行に `mouseenter`/`mouseleave` を仕込み、ホバー中だけ3Dクリスタルのcanvasを表示します。canvasの位置はマウス座標をそのまま使うのではなく、カーソルと同じ lerp のテクニックで少し遅れて追従させることで「浮遊感」を出しています。回転角度は常時わずかに進め続け、ホバー中は回転速度を上げることで「起きている」ような生き生きとした印象を強めています。

5. **`initSplitReveal()` — 単語単位の分割テキストリベール(SplitTextの再現)**
   見出しをあらかじめ `<span class="word"><span>単語</span></span>` という二重span構造にしておき、外側の `overflow: hidden` で切り取りつつ、内側のspanを `translateY(115%)` から `translateY(0)` へ動かすことで「下から立ち上がる」演出を作ります。各単語の `<span class="word">` にCSS変数 `--i`(出現順のインデックス)をJSから設定し、CSS側で `transition-delay: calc(var(--i) * 55ms)` を指定するだけで、単語ごとの時差(ステガー)が生まれます。

6. **`initScrollReveal()` — IntersectionObserverによるグラスモーフィズムカードの出現**
   `backdrop-filter: blur()` を使った半透明カードに、画面に入った瞬間だけ `is-visible` クラスを付与してフェードイン+上昇させます。一度表示したカードは `io.unobserve()` で監視を止め、再発火しないようにしています。

### つまずきやすいポイント(実装時に直面した問題と対策)

- **ネットワーク制限で実サイトを直接見られなかった**: このセッションの実行環境では `noomoagency.com` や `awwwards.com` への直接アクセスがネットワークポリシーでブロックされていました。そのため検索結果の要約情報(配色コード・カテゴリ・技術スタック・受賞歴など)のみを根拠に設計しています。実サイトの正確なレイアウトや3Dオブジェクトの形状・アニメーションのタイミングまでは確認できていないため、このデモは「公開情報から読み取れる範囲での解釈による再現」であり、実サイトの完全なコピーではありません。
- **`position: fixed` + `transform` によるスムーススクロールの罠**: 最初、コンテンツ全体を `position: fixed` にしてtransformでズラす実装を試しましたが、Playwrightでの動作確認中に `scrollIntoView()` を呼んでも要素が正しい位置に来ない(ページ座標とレンダリング座標がズレる)バグを実際に確認しました。原因は、`requestAnimationFrame` ループが毎フレーム無条件に `scrollTo()`(相当の処理)を呼び続け、外部からの本来のスクロール操作を上書きしてしまうことでした。対策として、①要素は普通の文書フローに置いたままにする、②ホイール操作があった時だけ慣性アニメーションのループを起動し、目標値に収束したら即座にループを止めて通常のスクロールに制御を返す、という設計に変更しました。これにより、アンカーリンクやキーボード操作、スクロールバーのドラッグと共存できるようになっています。
- **カウントアップやリベールの二重発火**: `IntersectionObserver` を使う演出では、`io.unobserve(entry.target)` を呼び忘れると画面の出入りのたびにアニメーションが再発火してしまいます。「1回だけ再生」させたい演出では、発火直後に観測を止めることを徹底しています。

## 使い方(コピーしてすぐ使う手順)

1. `index.html` を1ファイルごと自分のプロジェクトにコピーします(外部ライブラリ・画像・フォントへの依存は一切ありません)。
2. そのままダブルクリックで `file://` として開いても動作します。ローカルサーバー経由で見る場合は以下のようにします。

   ```bash
   cd sites/2026-08-08-noomo-showcase-3d-hover
   python3 -m http.server 8080
   # ブラウザで http://localhost:8080 を開く
   ```

3. プロジェクト一覧の項目数・タイトル・年・タグは `<div class="project-list">` 内の `.project-row` をコピー/削除するだけで増減できます。`.project-row` であれば自動的にホバー時の3Dクリスタルとカーソル拡大が有効になります。
4. カーソル追従の3Dオブジェクトの形状を変えたい場合は、`createIcosahedron()` の頂点(`VERTS`)・面(`FACES`)の定義を別の多面体(立方体・正八面体など)に差し替えてください。回転速度は `initProjectHoverCrystal()` 内の `angle.x` / `angle.y` の増分値で調整できます。
5. スムーススクロールの効き具合(重さ)は `initSmoothScroll({ lerp: 0.09 })` の `lerp` の値で調整できます。値を小さくするほど「重く」、大きくするほど「軽く」感じられます。
6. 配色を変えたい場合は、`:root` の `--bg` / `--fg` / `--accent` を書き換えるだけで、3Dクリスタルの光彩(`ctx.shadowColor` / `ctx.strokeStyle`)以外は全体に反映されます。3Dクリスタルの色も合わせて変えたい場合は `drawCrystal()` 内の該当箇所を書き換えてください。
7. グラスモーフィズムカードの枚数・見出し・本文は `.card-grid` 内の `.glass-card` をコピー/削除するだけで反映されます(`initScrollReveal(".glass-card")` が自動的に対象を検出します)。
