## 再現コードの仕組みの解説

`index.html` 1ファイルに CSS・JavaScript をすべてインラインで記述しています。実装は、他のプロジェクトにもそのままコピーできる小さな関数の集まりとして書かれています。

1. **`initScrollSpring(onUpdate)` — スクロール速度をバネで受け止める**
   毎フレーム `window.scrollY` の差分(＝そのフレームでのスクロール量)を「インパルス」として、`stretchVel`(速度)に加算します。その後、減衰振動(damped harmonic oscillator)の式 `springAccel = -STIFFNESS * stretch - DAMPING * stretchVel` で `stretch` の値自体をゼロへ引き戻す力を計算し続けます。これにより、スクロールしている間は値がぐんと伸び、スクロールをやめると勢いよく元(0)に戻りながら少し揺り戻す、「伸びて・跳ねて・馴染む」動きが生まれます。GSAPやLenisを使わずに、物理法則だけでバネのような質感を出す典型的な手法です。

2. **`createKineticType(canvas, lines)` — WebGLでテキストを歪ませる**
   見出しの文字は、DOM要素ではなく**1枚のテクスチャとしてWebGLに描画**しています。手順は以下の通りです。
   - オフスクリーンの `<canvas>` に、通常の Canvas 2D API (`fillText`)で大きな文字を描画する
   - それをWebGLのテクスチャとして読み込む(`texImage2D`)。ここで `gl.pixelStorei(gl.UNPACK_FLIP_Y_WEBGL, true)` を指定しないと、Canvas 2D(左上原点)とWebGLのUV座標(左下原点)の違いで文字が上下逆さまになる点に注意が必要でした
   - フルスクリーンの四角形(2枚の三角形)にこのテクスチャを貼り付け、フラグメントシェーダー内で `uStretch`(上記のバネの値)に応じてUV座標をずらす。中心からの縦距離が大きいほど横方向にずらす量を増やし、`sin` 波で位置ごとの位相をずらすことで、文字全体が一様にスライドするのではなく、しなるように歪む
   - WebGLが使えない環境(古いブラウザ等)では `createKineticType` が `false` を返すので、呼び出し側でCSSの `skewY` を使ったフォールバック表示に自動的に切り替わります

3. **`initCustomCursor()` — ホバーでラベル付きに変化するカーソル**
   ネイティブカーソルを `cursor:none` で消し、代わりに2つの `<div>`(ドットとリング)をマウス座標へ追従させます。ドットは追従の lerp 係数を大きく(＝速く)、リングは小さく(＝遅く)することで、2段階の「遅延トレイル」を演出しています。`data-cursor-label` 属性を持つ要素にマウスが乗ると、リングが拡大して属性値のテキスト(「View」「Say Hi」など)を表示します。`matchMedia("(pointer:fine)")` でマウス環境かどうかを判定し、タッチ端末では何もしないため、スマートフォンでは通常のタップ操作がそのまま使えます。

4. **`initRevealOnScroll(selector)` / `buildWorkGrid()` — スクロールで段階的に現れるカード・行**
   `IntersectionObserver` で要素が画面内に入ったタイミングを検知し、`is-visible` クラスを付けるだけのシンプルな実装です。実際の見た目の違い(何番目の要素がどれだけ遅れて現れるか)は、CSS側の `transition-delay: calc(var(--i, 0) * 60ms)` という「要素ごとのCSSカスタムプロパティ `--i`」で表現しています。JS側は「何番目か」をセットするだけで、あとはCSSのtransitionだけで波のようなスタガー(段階的)リビールが完成します。

5. **`initTabs(nav, cards)` — スライドするピル付きのタブ切り替え**
   Personal / Commercial / Collabs の3つのボタンをクリックすると、対応する `data-cat` を持つカードだけを表示し、それ以外を `display:none` にします。アクティブなボタンの背後にある「ピル」要素は、クリックされたボタンの `offsetLeft` / `offsetWidth` を読み取って `transform: translateX()` と `width` を更新するだけで、CSSの `transition` がなめらかなスライド移動を自動的に描画します。

6. **`initMagnetic(elements, strength)` — マウスに引き寄せられるボタン**
   マウス位置とボタン中心とのズレ量に `strength`(0〜1)を掛けた分だけ `translate()` する、非常にシンプルなマグネティックボタンです。マウスが離れると `translate(0,0)` にリセットして元の位置へなめらかに戻ります(戻りのなめらかさはCSSの `transition` に任せています)。

### つまずきやすいポイント(実装時に直面した問題と対策)

- **ネットワーク制限で実サイトを直接見られなかった**: このセッションの実行環境では、対象サイトのドメイン・`awwwards.com`・`cssdesignawards.com`・`tympanus.net`・`wikipedia.org` など、調査に使いたかった外部サイトへの直接アクセスがすべてネットワークポリシーでブロックされていました(`EGRESS_BLOCKED`、`curl` でも `CONNECT tunnel failed, response 403`)。そのため、Web検索結果に表示された要約文(受賞歴・使用技術・制作スタジオ自身の紹介文)のみを根拠に設計しており、実サイトの正確なレイアウトや配色、実際のシェーダーの中身までは確認できていません。このデモは「公開情報から読み取れる範囲での解釈による再現」であり、実サイトの完全な再現ではないことにご留意ください。
- **WebGLテクスチャの上下反転**: Canvas 2Dで描いた文字をそのままWebGLのテクスチャとして貼り付けたところ、文字が上下逆さま(かつ鏡像)に表示されるバグが発生しました。原因はCanvas 2D(左上が原点、Y軸下向き)とWebGLのUV座標系(左下が原点、Y軸上向き)の違いです。`gl.pixelStorei(gl.UNPACK_FLIP_Y_WEBGL, true)` を `texImage2D` の前に呼ぶことで解決しました。この設定を忘れるとテキストや画像をテクスチャとして使うほぼ全てのWebGLコードで同じ問題が起きるため、覚えておくと役立ちます。
- **`grid-template-columns: repeat(auto-fill, ...)` による余白**: ワークグリッドの列数をカード数より多く確保できる幅の画面では、`auto-fill` だとカードが2〜3枚しかなくても余った列がそのまま透明な空白として残ってしまいました。`auto-fill` を `auto-fit` に変えることで、コンテンツがない列が0幅に折りたたまれ、既存のカードが利用可能な幅いっぱいに広がるようになりました。

## 使い方(コピーしてすぐ使う手順)

1. `index.html` を1ファイルごと自分のプロジェクトにコピーします(外部ライブラリ・画像・フォントへの依存は一切ありません)。
2. そのままダブルクリックで `file://` として開いても動作します。ローカルサーバー経由で見る場合は以下のようにします。

   ```bash
   cd sites/2026-08-08-mat-voyce-kinetic-type-scroll
   python3 -m http.server 8080
   # ブラウザで http://localhost:8080 を開く
   ```

3. 見出しの文字列を変えたい場合は、`createKineticType(canvas, ["MOTION", "& TYPE"])` の第2引数(配列)を書き換えるだけです。配列の要素数が行数になります。
4. 伸縮・スナップバックの効き具合は `initScrollSpring()` 内の `STIFFNESS`(戻る速さ)・`DAMPING`(揺り戻しの少なさ)・`IMPULSE_SCALE`(スクロール量への感度)を調整すると変わります。値を小さくするほどゆったり伸びて、大きくするほどキビキビと元の形に戻ります。
5. カーソルのラベルを追加したい場合は、任意の要素に `data-cursor-label="任意の文字"` を付けるだけで、ホバー時にカーソルがそのラベルへ変化するようになります(`initMagnetic` に渡す要素リストにも加えると、マグネティック効果も同時に付きます)。
6. ワークカードの内容は `WORKS` 配列(`cat` / `title` / `desc`)を編集するだけで増減できます。`cat` の値を `personal` / `commercial` / `collabs` のいずれかにすると、対応するタブに自動で振り分けられます。
7. タブを追加・変更したい場合は、`#tabs` 内に `<button data-cat="...">` を追加し、`WORKS` 配列の該当する `cat` を持つカードを用意するだけで、`initTabs()` が自動的にピルの位置とフィルタリングを処理します。
