## 再現コードの仕組みの解説

`index.html` 1ファイルにCSS・JavaScriptをすべてインラインで記述しています。実装は他のプロジェクトにもそのままコピーできる、独立した小さな関数の集まりです。

1. **`initCustomCursor(ring, dot, magneticSelector)` — 2レイヤーのマグネティックカーソル**
   標準カーソルを `cursor:none` で消し、代わりにドット(即座にマウス座標へ追従)とリング(`requestAnimationFrame` ループの中で `ringX += (targetX - ringX) * 0.18` という単純な線形補間=イージングにより、遅れて滑らかに追従)の2レイヤーを重ねています。`data-magnetic` 属性を持つ要素にマウスが乗ると、リングの追従先(`targetX`/`targetY`)がマウス座標ではなくその要素の中心座標に切り替わり、リング自体も拡大して塗りつぶされたラベル付きの円に変化します。「要素の外形をなぞる」のではなく「要素の中心に吸い寄せられる」ことで、少ないコードでも意図的に強い引力を感じさせられるのがポイントです。

2. **`initGrain(el)` — CSSタイル画像によるフィルムグレイン**
   140×140pxの小さなオフスクリーンcanvasにピクセルごとランダムなグレースケール値を書き込み、`toDataURL()` でPNG化して画面全体を覆う要素の `background-image` にセットし、`background-repeat:repeat` で敷き詰めています。画面全体のピクセル数ぶんノイズを計算するのではなく、小さなタイル1枚だけを110msごとに再生成するため、フルHDの画面でも軽量に動作します。`mix-blend-mode:multiply` と低い `opacity` を組み合わせることで、コンテンツを邪魔しないうっすらとした質感になります。

3. **`initMarquee(track, wrapper, pxPerSecond)` — 継ぎ目のない無限マーキー**
   トラック要素の中身を1回複製して2セット並べ、`requestAnimationFrame` の中で経過時間(`dt`)ベースに `x` 座標を一定速度で減算していきます。トラック全幅の半分(=複製前の1セット分の幅)だけ進んだら `x` にその半分の幅を足し戻すことで、見た目には途切れなく無限に流れ続けるループになります。CSSアニメーションではなくJS駆動にしているのは、ホバー時に `paused` フラグを立てるだけで自然に一時停止・再開できるようにするためです。

4. **`initTextReveal(selector)` — 単語単位のスクロールリビール**
   見出しのテキストをスペースで単語に分割し、各単語を `overflow:hidden` の外側spanと、`transform:translateY(110%)` で下に隠れている内側spanの2重構造に組み替えます。`IntersectionObserver` が要素の40%が画面に入ったタイミングで `.is-in` クラスを付与すると、内側spanの `transform` がCSS transitionで `translateY(0)` に戻り、単語が下からせり上がるように現れます。各単語には出現順の連番を `--i` というCSSカスタムプロパティとして持たせ、`transition-delay:calc(var(--i,0) * 45ms)` で単語ごとに少しずつ遅延させることで、波のように文章が立ち上がっていくリズムを作っています。

5. **`initGridDistortion(cardEl, cols, rows, tone)` — 距離ベースの格子点ディストーション(このデモの中核)**
   WebGL/シェーダーを一切使わず、Canvas 2Dの線描画だけで「メッシュが計算的に歪む」演出を再現した部分です。仕組みは次の通りです。
   - カード要素内に `cols × rows` 個の格子点を等間隔に配置し、各点は「基準位置(`baseX`/`baseY`)」と「現在位置(`x`/`y`)」、「速度(`vx`/`vy`)」を持つ簡易的な物理オブジェクトとして扱います。
   - マウスがカード内にある間、各格子点は「カーソルとの距離」に応じて力を受けます。距離が半径(`radius`)以内であれば `force = 1 - dist/radius` という0〜1の値を計算し、`Math.atan2` で求めたカーソルから格子点への角度の方向へ、`force` に比例した力を速度に加算します(=カーソルに近いほど強く、遠いほど弱く押し出される「反発」)。
   - 同時に、常に「基準位置に戻ろうとする」ばねの力(`(baseX - x) * STIFFNESS`)を速度に加算し、`DAMPING` で速度を少しずつ減衰させることで、指を離すとゴムのように揺れながら元の格子に戻るような自然な動きになります。
   - 毎フレーム、格子点を横方向・縦方向にそれぞれ `ctx.lineTo` でつないで再描画するだけで、線が滑らかに波打つメッシュ・ディストーションが完成します。
   このような「距離に応じた反発力 + ばねによる復元」という組み合わせは、WebGLの頂点シェーダーで書かれることが多い演出ですが、格子点の数が数百程度であればCanvas 2Dの線描画でも十分軽量に成立します。

## 使い方(コピーしてすぐ使う手順)

1. `index.html` を1ファイルごと自分のプロジェクトにコピーします(外部ライブラリ・画像・フォントへの依存は一切ありません)。
2. そのままダブルクリックで `file://` として開いても動作します。ローカルサーバー経由で見る場合は以下のようにします。

   ```bash
   cd sites/2026-08-01-2xa-studio-code-grid-cursor
   python3 -m http.server 8080
   # ブラウザで http://localhost:8080 を開く
   ```

3. **マグネティックカーソルを別の要素にも効かせたい場合**は、対象の要素に `data-magnetic` 属性を付けるだけで構いません。`initCustomCursor()` 側の変更は不要です。
4. **グリッド・ディストーションを別のカードに適用したい場合**は、その要素の中に `<canvas></canvas>` を1枚置いた上で、`initGridDistortion(cardEl, cols, rows, tone)` を呼び出してください。`cols`/`rows` を増やすほど格子が細かくなり、`tone` に渡すCSSカラー文字列(例: `"#1c1c1c"`)が線の色になります。
5. **反発の強さや戻る速さを調整したい場合**は、`initGridDistortion()` 内の `PUSH`(押し出しの最大量)・`STIFFNESS`(元の位置へ戻る力)・`DAMPING`(揺れの減衰)の3つの定数を書き換えます。`STIFFNESS` を大きくすると硬いバネのようにすぐ戻り、`DAMPING` を1に近づけるほど揺れが収まりにくくなります。
6. **配色を変えたい場合**は、`:root` の `--ink` と `--paper` の2値だけを書き換えれば、そこから派生する `--ink-70` などの濃淡も含めて全体の配色が連動して変わります。
7. **マーキーの流す速度**は `initMarquee(track, wrapper, pxPerSecond)` の第3引数(px/秒)を、**テキストリビールの立ち上がる速さ**はCSSの `.reveal-word span` の `transition-delay:calc(var(--i,0) * 45ms)` の `45ms` を、それぞれ調整してください。

### つまずきやすいポイント(実装時に直面した問題と対策)

- **ネットワーク制限で実サイトを一度も見られなかった**: このセッションの実行環境では `2xa.studio` 本体はもちろん、`www.awwwards.com`・`www.cssdesignawards.com`、さらには動作確認用に立ち寄ろうとした無関係の `example.com` まで、外部ドメインへの直接アクセスがほぼ一律で `EGRESS_BLOCKED` として拒否されました。そのため本デモは、WebSearchのスニペットに含まれていた「コード駆動」「2色構成 `#0F0F0F`/`#FDFDFD`」「HTML5・CSS・JS」「Developer Award」というキーワードのみを手がかりに設計した解釈的な再現であり、実際のピクセル単位のレイアウトや演出の正確な内容は確認できていません。
- **グレインを画面いっぱいのcanvasで愚直に描くとブロック状になる**: 最初、画面全体を覆う `<canvas>` を小さいピクセル数(96×96)で描いてCSSで100%に引き伸ばす実装にしたところ、1粒が十数pxもある不自然に粗いブロック模様になってしまいました。小さなタイル画像を `background-repeat:repeat` で敷き詰める方式に変更し、タイル自体の解像度(140×140px)と実際の表示サイズを一致させることで、粒の細かい自然なフィルムグレインになりました。
- **格子点の反発方向を「カーソル→点」の向きにする**: 反発の角度を `Math.atan2` で計算する際、引数の順序を「点→カーソル」で取ってしまうと格子がカーソルに吸い寄せられる(反発ではなく誘引になる)向きになってしまいます。`dx = p.baseX - mouse.x` のように「点の基準位置からカーソル位置を引く」順序にすることで、カーソルから遠ざかる向きに正しく押し出されるようになりました。
- **`STIFFNESS` と `DAMPING` のバランス**: ばねの力を強くしすぎる(`STIFFNESS` を大きくする)と、格子点が基準位置を通り越して逆方向に振動し続ける発振状態になりやすい問題がありました。`STIFFNESS:0.08` 程度に抑えつつ `DAMPING:0.82` で速度を毎フレーム18%ずつ削ることで、押し出された格子点が数フレームのうちに滑らかに(振動せず)元の位置へ収束するようになりました。
