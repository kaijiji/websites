## どんなサイトか

Veroは、花嫁が身につけたウェディングドレスを、職人技とテクノロジーの融合によって「永遠に残る彫刻(スカルプチャー)」へと仕立て直す、ニューヨーク発のラグジュアリー・ファインアートスタジオです。ブランド名は創業者の旧姓「Ontiveros」に由来し、ロゴには「エレガンス・変容・新しい始まり」を象徴するカラーリリー(オランダカイウ)の花形と、ギリシャ・ローマ彫刻に登場する舞う女性像(マイナデス)のモチーフが使われています。

サイト自体も、この「ドレス(布・記憶)が彫刻(永遠の形)へと変容する」というブランドの核となるストーリーを、Webページの表現そのもので語ろうとしている点が高く評価されています。Awwwardsの分類タグには WebGL・パララックス(視差効果)・フルスクリーン・大判の背景画像・タイポグラフィ・アニメーションが挙げられており、Next.js + Sanity(CMS)+ WebGLという構成で、静かで上質な「quiet luxury」的トーンの中に、スクロールに連動した滑らかなビジュアル演出が組み込まれていると考えられます。

### 印象的だった点(推測を含む)

- **「変容」というブランドコンセプトを視覚効果として体現している**点。単なる装飾的なWebGL演出ではなく、"素材が別の何かへ移り変わる"様子そのものを画面上の表現に落とし込んでいると考えられます。
- 大判のフルスクリーン画像とタイポグラフィを中心とした、余白の多い**エディトリアルなレイアウト**。
- スクロールに連動した**パララックス(視差)効果**による奥行きの演出。
- ラグジュアリーブランドらしい、動きの少ない・上品な速度でのアニメーション設計。

## 使われている技術・ライブラリの推測

- **Next.js** — Reactベースのフロントエンドフレームワーク(Awwwardsのタグ情報より)。
- **Sanity** — ヘッドレスCMS。商品/コミッション事例などのコンテンツ管理に使われていると推測。
- **WebGL** — フルスクリーンの画像演出やパララックス、画像切り替えの表現に使用されていると推測。
- おそらく **GSAP + ScrollTrigger** 相当のスクロール連動アニメーションライブラリ(多くのAwwwards受賞サイトで標準的に使われる構成のため)。

## 再現デモの仕組み

このフォルダの `index.html` は、上記の技術構成を**外部ライブラリを一切使わずWeb標準APIだけ**で再現した学習用デモです。実際のVeroのソースコードではなく、「WebGLでの画像ディゾルブ切り替え」「スクロール連動パララックス」「行内ワード単位のテキストリベール」という**表現技法そのもの**を、ゼロから実装しています。

### 1. WebGLによるノイズディゾルブ切り替え(`createScrollDissolveWebGL`)

- フルスクリーンの`<canvas>`にWebGL(生API、Three.js等は不使用)で四角形(quad)を1枚描画します。
- フラグメントシェーダー内で疑似ノイズ関数(`hash` / `noise`)を使い、UV座標ごとにランダムな閾値を生成します。
- スクロール進捗 `uProgress`(0〜1)とノイズ値を`smoothstep`で比較し、**素材A(布のような柄)**から**素材B(彫刻のような造形)**へ、単純なクロスフェードではなく「じわじわと溶けるように」切り替わるディゾルブ効果を作っています。
- 切り替わりの境界には、薄い金色の発光ラインを重ねることで、上質な質感を演出しています。
- **著作権対策**: 使用している2枚の「画像」は、実際の写真ではなく`Canvas2D`でその場生成したオリジナルのグラデーション+ベジェ曲線イラストです。外部の画像ファイルを一切ダウンロード・使用していません。

### 2. スクロール連動パララックス

- `getProgress()`関数が、ヒーローセクションが画面内をどれだけ通過したかを`0〜1`の値として返します。
- `getPointer()`関数がマウス座標を`-1〜1`に正規化して返し、シェーダー内でUVを微妙にずらすことで、視差(パララックス)による奥行き感を出しています。
- 目標値に対して現在値を`+= (target - current) * 0.08`のように少しずつ近づける**lerp(線形補間)**を使うことで、値がカクカク変化せず、慣性のある滑らかな動きになります(GSAPのスムーススクロールや`ScrollTrigger`の`scrub`オプションと同様の考え方です)。

### 3. 行内ワード単位のテキストリベール

- `data-reveal`属性を付けた段落を、JavaScriptで単語ごとの`<span>`に分割します(GSAPの`SplitText`プラグインが行う処理を、正規表現の分割だけで簡易再現)。
- `IntersectionObserver`で各単語が画面内に入ったタイミングを検知し、`is-visible`クラスを付与。
- CSSの`transition-delay`を単語のインデックスに応じてずらすことで、**単語が少しずつ時間差で浮かび上がる**リベール効果を実現しています。

## 使い方(自分のプロジェクトへの組み込み方)

1. `index.html`をそのままコピーして開けば、単体で動作します(外部ライブラリ不要)。
2. 自分のヒーロー画像に差し替えたい場合は、`makeTexture()`に渡している描画処理を、実際に持っている画像を読み込む処理に置き換えてください。

   ```js
   // 例: 実際の画像ファイルをテクスチャとして使う場合
   function makeTextureFromImage(url) {
     const tex = gl.createTexture();
     gl.bindTexture(gl.TEXTURE_2D, tex);
     // 読み込み前の仮テクスチャ(1x1の単色)を先に設定しておく
     gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, 1, 1, 0, gl.RGBA, gl.UNSIGNED_BYTE, new Uint8Array([0,0,0,255]));

     const img = new Image();
     img.crossOrigin = 'anonymous';
     img.onload = () => {
       gl.bindTexture(gl.TEXTURE_2D, tex);
       gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, img);
       gl.generateMipmap(gl.TEXTURE_2D);
     };
     img.src = url;
     return tex;
   }
   ```

3. `createScrollDissolveWebGL(canvas, { getProgress, getPointer })`の`getProgress`を、自分のページのスクロール量計算ロジックに差し替えれば、任意のセクションで同じディゾルブ効果を使い回せます。
4. テキストリベールを使いたい要素には、`class="reveal-word"`のCSSと`data-reveal`属性付きの構造をそのまま流用できます。
