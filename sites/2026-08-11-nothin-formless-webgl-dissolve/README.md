## 評価されている理由・印象的だった点（検索でわかった範囲）

- 「NOTHIN'（何もない）」という名前でありながら、「空白だからこそ何にでもなれる」という逆説をブランドコンセプトの核に据えている点。
- ファッション/ラグジュアリー領域のクライアント向けに、ブランディングとAIを組み合わせるという現代的なポジショニング。
- 制作クレジットにWebGL・シェーダーが明記されていることから、単なる静的なエディトリアルサイトではなく、視覚表現そのもので「形を変え続けるスタジオ像」を体現しようとしていると推測されること。

このデモでは、上記のコンセプトを手がかりに、「**決まった形を持たず変形し続けるWebGLオブジェクトのヒーロー**」「**ノイズを使ったシェーダー・ディゾルブでスクロールに連動して画像が”焼け跡”のように切り替わるギャラリー**」「**行単位でせり上がるテキストリビール**」「**ラベル付きカスタムカーソル**」の4つを、外部ライブラリなしのバニラJS・生WebGL(GLSL)だけで独自に組み立てています。

## 使われている技術・ライブラリの推測

検索結果から確認できた事実は次の4点のみです。

- **Webflow** — CMS/ノーコード制作基盤（推測: マークアップ・CMS部分）
- **GSAP** — スクロール連動アニメーション全般に使われていると推測されるアニメーションライブラリ
- **WebGL** — 3D/シェーダー表現に使われている技術
- **shaders（GLSLシェーダー）** — WebGL上のカスタムビジュアル表現

このデモでは、GSAPやWebflowそのものは使わず、**生のWebGL(GLSL)とバニラJavaScript・CSSのみ**で、「形を持たないオブジェクトが変形し続けるヒーロー」「ノイズシェーダーによる画像ディゾルブ切り替え」という体験の核を再現しています（学習目的で仕組みを理解しやすくするため、意図的に外部ライブラリへの依存をゼロにしています）。

## 再現コードの仕組みの解説

`index.html` 1ファイルにCSS・JavaScriptをすべてインラインで記述しています。5つの仕組みはそれぞれ独立した関数/コードブロックになっており、他のプロジェクトにもコピーして使えます。

### 1. ヒーロー: 「形のないもの」WebGLレイマーチング

`initFormlessBlob('hero-gl')` にまとまっています。

- レイマーチング(Signed Distance Field / SDF)という手法で、**球(sphere)・トーラス(torus)・立方体(box)** という3つの異なる原始形状の距離関数を、`cos(phase)` を使った重みで連続的にブレンドしています。位相`phase`が一周する間に「球が優勢 → トーラスが優勢 → 立方体が優勢 → また球へ」と滑らかに移り変わるため、オブジェクトが決まった形を持たず変形し続けます。
- さらに`sin`波を3方向に重ねた簡易ノイズ(`wobble`)を距離関数に足すことで、金属というより粘土・液体のような有機的な揺らぎを加えています。
- マウス位置をカメラの回転角(`uMouse`)に渡し、カーソルの動きに応じて視点がゆっくり追従するパララックスを実現しています。

### 2. ノイズシェーダー・ディゾルブ・ギャラリー(スクロール連動)

`initDissolveGallery(...)` にまとまっています。CSSの`position:sticky`でセクションを画面にピン留めし(GSAP ScrollTriggerの`pin:true`に相当。JSでの座標計算が最小限で済むのが利点)、スクロール量から0〜(スライド数-1)の連続的な進行度を計算します。

```js
const rect = wrap.getBoundingClientRect();
const scrollable = wrap.offsetHeight - innerHeight;
const raw = scrollable > 0 ? -rect.top / scrollable : 0;
```

画像は実サイトのものを使わず、**Canvas 2Dでその場生成した抽象模様**をWebGLテクスチャとして使っています。2枚のテクスチャの間は、疑似乱数ノイズ`noise(uv)`を閾値`uLocalT`と比較する`smoothstep`でマスクし、閾値付近だけゴールドの縁取りを加算することで、単純なopacityクロスフェードより「焼け跡が広がっていく」ような質感のある転換にしています。

### 3. 行単位のマスクリビール

見出しを`<div class="line-mask"><p class="line-inner">…</p></div>`という2重構造で包みます。外側`.line-mask`は`overflow:hidden`、内側`.line-inner`は`transform:translateY(115%)`で画面下に隠れています。`IntersectionObserver`で画面内に入ったことを検知すると`.in-view`クラスを付け、`translateY(0)`へcubic-bezierで戻すことで、テキストが下からせり上がるように現れます(GSAP SplitText + ScrollTrigger相当の効果)。各行の`transition-delay`をJSでインデックスに応じてずらし、スタガー(段違い)演出にしています。

### 4. ラベル付きカスタムカーソル

画面中央の小さな丸(`#cursor-dot`)がmousemove座標へ毎フレームlerp(線形補間)で追従します。`data-cursor="表示したい文字"`属性を付けた要素にマウスが乗ると、丸が拡大し、右側にラベル(例: "Read" "Look" "Say hi")がフェードインします。

## 使い方(コピーしてすぐ使う手順)

1. `index.html`をそのままブラウザで開くだけで動作します(外部ライブラリ・ビルド不要)。
2. 自分のプロジェクトに個別の機能だけ移植したい場合は、以下の単位でコピーしてください。
   - **形のないもの ヒーロー**: `<canvas id="hero-gl">`と`initFormlessBlob()`関数、対応するCSS(`#hero-gl`)をコピーし、`initFormlessBlob('hero-gl')`を呼ぶだけ。
   - **ディゾルブ・ギャラリー**: `.pin-wrap` / `.pin-sticky` / `<canvas id="dissolve-gl">`のHTML構造とCSS、`initDissolveGallery()`関数をコピー。`slides`配列の`colors`と`shape`(`'arcs'` / `'rays'` / `'dots'`)を変えるだけで別の見た目になります。実際の写真を使いたい場合は、`makeSlideCanvas`の代わりに`<img>`を読み込んで`gl.texImage2D`に渡してください。
   - **行単位マスクリビール**: `.line-mask` / `.line-inner`のペアをコピーし、対象要素を`.line-mask`で包んでください。IntersectionObserverの部分もそのままコピーすれば動きます。
   - **カスタムカーソル**: `#cursor`まわりのHTML/CSSと該当スクリプトをコピーし、ラベルを出したい要素に`data-cursor="表示文字"`を付けてください。
3. 配色(`:root`のCSS変数 `--ink` / `--paper` / `--gold`)を書き換えれば、自分のブランドカラーに合わせて見た目を調整できます。

## 動作確認

Playwright(Chromiumのソフトウェアレンダリング, `--use-gl=swiftshader`)でヒーロー・マニフェスト・ディゾルブギャラリー(進行度 5%/35%/65%/95%地点)・CTAまでのスクロールを一通りスクリーンショットで確認し、コンソールエラーが出ないこと(faviconの404を除く)、ヒーローのSDFブレンドが球→トーラスへ滑らかに変形すること、ディゾルブがノイズ状の境界とゴールドの縁取りを伴って切り替わることを確認済みです。
