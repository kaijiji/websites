## 評価されている理由・印象的だった点

検索結果(Codrops・abduzeedoの記事)から読み取れる範囲では、このサイトは次の点が評価されています。

- **スイス・スタイル(International Typographic Style)**のオレンジ・白・黒の3色構成と、タイトな列(カラム)グリッド。個人サイトというより印刷物の年鑑のように見える、規律あるレイアウト
- **Three.jsとGLSL**を使い、プロジェクトのプレビュー画像にジオメトリを組み込むことで、タイポグラフィの階層を崩さずに奥行きを持たせている
- **Figma風の「定規(ルーラー)」機能**。中央のクロス(十字)をクリックするとページタイトルを囲む1px幅のガイド線が `getBoundingClientRect()` を使って表示され、さらに自分でクリックした場所に測定用のマーカーを自由に置ける
- `Option + G` のキーボードショートカットで、サイト全体に使われているレイアウトグリッドをオン/オフでき、デザインの裏側の構造を覗ける
- 実装は **Vanilla JavaScript + SCSS(BEM)+ JSONデータ**で、CMSを使わず開発者自身が完全にコントロールしている

このデモでは、上記のうち「①スイス・スタイルのグリッドレイアウト」「②`G`キーで切り替えるレイアウトグリッド・オーバーレイ」「③Figma風の計測(ルーラー)ツール(要素のサイズ表示・クリックでの自由なマーカー設置)」「④Three.jsの代わりに素のCanvas 2Dで作った回転ワイヤーフレーム」の4つを、外部ライブラリなしのバニラJS/CSSで再現しています。

## 使われている技術・ライブラリの推測

検索結果の要約から確認できた情報として、以下が挙げられています。

- **Three.js + GLSLシェーダー** — プロジェクトプレビューに組み込まれたジオメトリの3D表現

- **SCSS + BEM** — CSS設計手法

## 再現コードの仕組みの解説

`index.html` 1ファイルに CSS・JavaScript をすべてインラインで記述しています。実装は、他のプロジェクトにもそのままコピーできる3つの関数として書かれています。

1. **`initGridOverlay(overlayEl, toggleBtn, keyName)` — レイアウトグリッド・オーバーレイ**
   ページ本体のグリッドと同じCSS変数(`--col-count`・`--gutter`・`--margin`)を共有した、列とベースライン(行送り)だけを描く透明なオーバーレイ要素(`#grid-overlay`)を用意しておき、ボタンクリックまたは指定したキー(このデモでは`g`)で`is-visible`クラスをトグルするだけの、非常にシンプルな仕組みです。本物のレイアウトと寸分違わず重なるのは、CSS変数を共有しているためです。

2. **`initMeasureTool(options)` — Figma風の計測(ルーラー)ツール**
   - **ハイライト表示**: `measure-mode`が有効な間、`data-measure`属性を持つ要素の上にマウスが乗ると、`el.getBoundingClientRect()`で取得した`left/top/width/height`をそのまま使い、使い回し用の1つの枠要素(`#measure-box`)を該当位置・サイズに配置し、幅×高さのラベルを表示します。要素ごとにDOMを作り直さず、1つの要素を毎回動かすだけなので軽量です。
   - **マーカー設置**: 計測対象ではない場所をクリックすると、その`clientX, clientY`座標に、上下左右いっぱいに伸びる点線の十字ガイドと座標ラベルを持つ`.marker`要素を生成して`body`に追加します。マーカー自身をクリックすると`remove()`で消えます。
   - 計測対象の検出には、生の`mouseover`/`click`イベントを`document`で1つだけ監視し、`event.target.closest('[data-measure]')`で判定するイベントデリゲーションを使っているため、後からカードを増やしても追加のイベント登録は不要です。

3. **`initWireframeCanvas(canvas)` — Three.jsなしで作る回転ワイヤーフレーム**
   正20面体の12頂点の座標を黄金比(`t = (1+√5)/2`)から計算し、頂点間の距離が一定値未満のペアだけを「辺」として抽出します。毎フレーム、
   - Y軸回転 → X軸回転の順に頂点座標を回転行列で変換し、
   - `f = dist / (dist - z)` という単純な透視除算(遠いほど`f`が小さくなる)で2D座標に変換して、
   `ctx.lineTo`で辺を線描します。これはThree.js/WebGLを使わず、Canvas 2Dの範囲だけで「立体的に回転しているように見える」表現を作る最小構成のテクニックです。

### つまずきやすいポイント(実装時に直面した問題と対策)

- **ネットワーク制限で実サイトを直接見られなかった**: このセッションの実行環境では`corentinbernadou.com`・`awwwards.com`・`tympanus.net`・`abduzeedo.com`への直接アクセスが`EGRESS_BLOCKED`でした。そのため検索結果に表示された記事の要約(使用技術・コンセプトの説明文)のみを根拠に設計しており、実サイトの正確な配色・タイポグラフィ・ジオメトリの見た目までは確認できていません。このデモは「公開情報から読み取れる範囲での解釈による再現」であり、実サイトの完全な再現ではないことにご留意ください。
- **グリッドオーバーレイがズレる**: オーバーレイ用のグリッドを独自のCSS変数で作ってしまうと、本文側のレイアウトが変わった時にズレます。`--col-count`・`--gutter`・`--margin`を`:root`で1箇所定義し、本文とオーバーレイの両方から同じ変数を参照することで、常に一致させています。
- **計測ボックスの要素数**: ホバーのたびに枠要素を`createElement`すると、素早くマウスを動かした時に大量のDOM要素が残ってしまいます。枠は`#measure-box`1つだけを使い回し、位置とサイズだけを毎回書き換える設計にすることでこれを回避しています。
- **マーカーのガイド線が画面外まで届かない**: `top:0; bottom:0;`だけでは、`position:fixed`内の要素が親要素の外まで伸びきらないことがあるため、線の要素自体を`position:fixed`にして`inset`を直接指定し、常にビューポート全体を基準にしています。

## 使い方(コピーしてすぐ使う手順)

1. `index.html` を1ファイルごと自分のプロジェクトにコピーします(外部ライブラリ・画像・フォントへの依存は一切ありません)。
2. そのままダブルクリックで `file://` として開いても動作します。ローカルサーバー経由で見る場合は以下のようにします。

   ```bash
   cd sites/2026-08-11-corentin-bernadou-swiss-grid-ruler
   python3 -m http.server 8080
   # ブラウザで http://localhost:8080 を開く
   ```

3. 画面右上の「グリッド表示」ボタン、または`G`キーで、レイアウトグリッドのオン/オフを確認できます。
4. 「定規モード」ボタン、または`R`キーを押してから、カードにマウスを乗せるとサイズが表示され、何もない場所をクリックするとマーカー(十字ガイド)を設置できます。マーカーは再クリックで削除、「マーカー消去」ボタンで一括削除できます。
5. 自分のサイトに計測ツールだけ移植したい場合は、計測したい要素に`data-measure`属性を付けて`initMeasureTool({...})`を呼ぶだけで動きます。
6. グリッドの列数や余白を変えたい場合は、`:root`の`--col-count`・`--gutter`・`--margin`・`--baseline`を書き換えるだけで、本文とオーバーレイの両方に反映されます。
7. ワイヤーフレームの形を変えたい場合は、`initWireframeCanvas`内の`raw`配列(頂点座標)と辺の距離しきい値(`d < 2.1`)を調整すると、正20面体以外の多面体にも応用できます。
