## 評価されている理由・印象的だった点

検索で得られた紹介文からは、Son Daven のサイトが「長編の不動産ストーリーテリング」を、単調にならないよう複数の演出パターンを重ねて見せている点が評価されていると読み取れます。

- 詩的なプロローグの文章から始まり、シネマティックなローダーとともに世界観に引き込む導入
- スクロールに合わせて「章(チャプター)」が切り替わっていくリズムのある長編ストーリーテリング構成
- 季節ごとのレンダリング(夏景色・冬景色)を、押し続ける(hold)ことで比較できるマイクロインタラクション — 単純なスライダーではなく「長押し」という能動的な操作に紐づけている点がユニーク
- 投資指標やインフラマップ、インタラクティブなロケーションカードなど、情緒的な演出と実務的な情報設計を両立させている構成

## 再現コードの仕組みの解説

`index.html` 1ファイルに CSS・JavaScript をすべてインラインで記述しています。実装は、他のプロジェクトにもそのままコピーできる小さな関数の集まりとして書かれています。

1. **`initPreloader(onDone)` — シネマティック・プリローダー**
   0%からじわじわ増える数値カウンター(`setInterval` で「終盤ほど増分を小さくする」ことで、それっぽい減速感を演出)とバーを表示し、100%に到達したらローダー全体を `transform: translateY(-100%)` で上へスライドさせて退場させます。完了後に呼ばれるコールバック(`onDone`)でパララックスなど他の初期化を始めることで、「読み込み中は動かさない」演出上の順序を保証しています。

2. **`initParallax(layers)` — 多層パララックス**
   `{el, speed}` の配列を受け取り、`requestAnimationFrame` のループの中で `window.scrollY * speed` の分だけ各レイヤーを `translate3d` でずらし続けます。speed が小さいレイヤーほど背景のように遅れて動くため、奥行きのある視差効果になります。

3. **`getScrollProgress(spacerEl)` — ピン留めスクロールの進捗計算(共通基盤)**
   高さを大きく確保した「spacer」要素の `getBoundingClientRect()` から、その要素が画面を通過する進捗を 0〜1 の値として計算します。中身は `position: sticky` で画面に固定しつつ、この進捗値でアニメーションを進める——という「ピン留めスクロール」演出の土台になる関数です。

4. **`initChapterScroll()` — 章立てストーリーテリング**
   スクロールの進捗(0〜1)を章の数で等分し、今どの章の区間にいるかを `Math.floor(progress * chapters.length)` で判定します。区間が変わった瞬間だけ見出し・本文・ドットのアクティブ状態を書き換えることで、無駄な再描画を避けつつ「スクロールするほど場面が進む」体験を作っています。さらに区間内の局所的な進み具合を使って背景の光の強さも連続的に変化させ、単なる切り替えに留まらない揺らぎを加えています。

5. **`initHoldCompare(frameEl, {duration})` — 長押しビフォーアフター比較**
   `mousedown`/`touchstart` で計測を開始し、`requestAnimationFrame` ループの中で経過時間を `duration` で割った値を「めくれ具合」として `clip-path: inset(0 X% 0 0)` に適用します。押し続けるほど冬景色のレイヤーが左から右へ現れていき、指を離すと現在値から少しずつ 0 へ戻るアニメーションに切り替わります。単純な `mousemove` 追従スライダーではなく「押している時間」を入力にしている点が、通常のビフォーアフタースライダーとの違いです。

6. **`initLocationCards(gridEl, items)` — データ駆動のロケーションカード**
   カード情報の配列を受け取り、テンプレート文字列でDOMを生成します。展開アニメーション自体はCSSの `max-height` トランジション(`:hover`)だけで完結させ、JavaScript側はデータからHTMLを組み立てる役割に限定しています。データを増減させるだけでカードの数を調整できます。

### つまずきやすいポイント(実装時に直面した問題と対策)

- **ネットワーク制限で実サイトを直接見られなかった**: このセッションの実行環境では `sondaven.com`・`awwwards.com`・`cssdesignawards.com`・`uicoach.io` など、調査に使いたかったサイトへの直接アクセスがすべてネットワークポリシーでブロックされていました。そのため検索結果の要約文(受賞カテゴリ・使用ツール・演出の紹介文)のみを根拠に設計しており、実サイトの正確なレイアウトや配色、細かいタイミングまでは確認できていません。このデモは「公開情報から読み取れる範囲での解釈による再現」であり、実サイトの完全な再現ではないことにご留意ください。
- **長押し中に指が離れた場合の巻き戻り**: `initHoldCompare()` で単純に「離したら0へ戻す」だけだと、途中まで進んだ状態から急に先頭へ飛んでしまい不自然でした。離した瞬間の `current` 値を保持し、そこから毎フレーム少しずつ減らす実装にすることで、自然な巻き戻りアニメーションになります。
- **章の切り替わり判定でのちらつき**: `getScrollProgress()` の値は毎フレーム微妙に変動するため、区間番号が変わるたびに毎回DOMを更新すると不要な再描画が発生します。`lastIndex` で直前の区間番号を保持し、実際に区間が変わったときだけ `textContent` を更新するようにして無駄な描画を防いでいます。

## 使い方(コピーしてすぐ使う手順)

1. `index.html` を1ファイルごと自分のプロジェクトにコピーします(外部ライブラリ・画像・フォントへの依存は一切ありません)。
2. そのままダブルクリックで `file://` として開いても動作します。ローカルサーバー経由で見る場合は以下のようにします。

   ```bash
   cd sites/2026-08-08-son-daven-hold-compare-story
   python3 -m http.server 8080
   # ブラウザで http://localhost:8080 を開く
   ```

3. 章立てストーリーテリングの内容・章数は `initChapterScroll()` 内の `chapters` 配列を書き換えるだけで調整できます(章数を増やすと自動的に区間の割り当ても再計算されます)。
4. 長押し比較の速さは `initHoldCompare(el, { duration: 1400 })` の `duration`(ミリ秒)を変更するだけで調整できます。値を大きくするほどゆっくりめくれます。
5. ロケーションカードの枚数・内容は `initLocationCards()` に渡す配列を書き換えるだけで反映されます。
6. 配色を変えたい場合は、`:root` の `--bg` / `--fg` / `--accent` / `--forest-1` / `--forest-2` / `--snow-1` / `--snow-2` の各CSS変数を書き換えるだけで全体に反映されます。
