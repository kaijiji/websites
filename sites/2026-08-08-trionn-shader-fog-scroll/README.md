# Trionn 風 表現デモ — GLSLシェーダー霧 / スクロールスクラブ / マグネティックカード

## 評価されている理由・印象的だった点

Codrops記事の紹介文からは、Trionnのサイトが「アニメーション・WebGL・インタラクションを別々の仕組みとしてではなく、ひとつの統合された体験として設計している」点が評価されていると読み取れます。

- ヒーロー部分の背景が、粒子ではなく**1枚のフラグメントシェーダー**で描かれた「霧/煙」であること。パーティクルを大量に描画するより軽量でありながら、有機的に揺らめく質感を出している
- スクロールに連動して、ピン留め(画面に固定)されたセクションの中身が段階的に切り替わっていく「スクラブ」演出
- 見出しや本文を文字・単語・行単位で分解して、順番にアニメーションさせるテキスト演出(SplitText的な手法)
- 慣性のあるなめらかなスクロール(Lenis)と、それに同期したスクロールアニメーション
- クリックやインタラクションに反応するWeb Audio(音)の演出

このデモでは、上記のうち「シェーダー霧」「スクロールスクラブ」「テキスト分解リビール」「マグネティックなカードのチルト」「アンビエントサウンド」の5つの仕組みを、外部ライブラリなしのバニラJS/CSS/WebGLで再現しています。

## 使われている技術・ライブラリの推測

Codrops記事の要約から確認できた情報として、以下が挙げられています。

- **GSAP + `@gsap/react`** — タイムライン制御、ページ遷移、コンポーネント単位のアニメーション
- **ScrollTrigger** — スクロール連動のリビール・ピン留め・スクラブ
- **SplitText** — 文字/単語/行単位のテキストアニメーション
- **Three.js** — ヒーローのシンボル、Servicesセクション、作品グリッドのインタラクション
- **Lenis** — GSAPと同期させたなめらかなスクロール
- 霧/煙の表現は、パーティクルではなく**1枚のフルスクリーン・フラグメントシェーダー**で描かれており、FBM(フラクタルノイズ)を重ねた上でドメインワーピング(ノイズでノイズ自体の座標を歪ませる手法)によって煙のような有機的な流れを作っている、との説明がありました

このデモでは、GSAP・Three.js・Lenisといった外部ライブラリを一切使わず、**素のWebGL(生のGLSL)とバニラJavaScript・CSSだけ**で、それぞれが実現しているであろう体験の骨格を再現しています。

## 再現コードの仕組みの解説

`index.html` 1ファイルに CSS・JavaScript をすべてインラインで記述しています。実装は、他のプロジェクトにもそのままコピーできる小さな関数の集まりとして書かれています。

1. **`createFogShader(canvas)` — GLSLシェーダーによる霧の表現**
   Three.jsを使わず、生のWebGL APIでフルスクリーンの四角形(2枚の三角形)を描画し、そこに1枚のフラグメントシェーダーを適用しています。シェーダーの中身は次の3ステップです。
   - `hash()` → `noise()`(格子点をハッシュ関数で乱数化し、`smoothstep`で滑らかに補間する定番の「Value Noise」)
   - `fbm()`(Fractional Brownian Motion。ノイズを周波数を上げながら振幅を下げて5回重ねることで、雲のような自然な濃淡を作る)
   - ドメインワーピング(`fbm()`の結果を使って、もう一度`fbm()`に渡す座標自体をずらす。これにより渦を巻くような有機的な流れが生まれる)
   さらに `uTime` で座標のy方向を時間とともにずらすことで「下から上へ立ちのぼる」動きを、`uMouse`(ポインタ位置を線形補間で滑らかに追従させた値)でカーソル周辺だけを発光させる効果を加えています。WebGLが使えない環境では `false` を返すので、呼び出し側でCSSグラデーションのフォールバックに切り替えます。

2. **`splitIntoChars(el)` / `revealOnEnter(el)` — 文字単位のテキストリビール**
   見出しのテキストを1文字ずつ `<span class="char">` に分解し、各要素に `--i`(文字番号)というCSSカスタムプロパティを持たせます。CSS側で `transition-delay: calc(var(--i) * 22ms)` とすることで、文字番号が大きいほど遅れてフェードインする「波のような」リビールになります。`IntersectionObserver` で要素が画面に入ったタイミングを検知し、親要素に `is-visible` クラスを付けるだけで済むシンプルな実装です。

3. **`initScrollScrub(spacerEl, onProgress)` — ピン留めスクロールの進捗計算**
   高さを大きく確保した `spacer` 要素(このデモでは `height:300vh`)の `getBoundingClientRect()` から、その要素が画面を通過する進捗を0〜1の値として毎スクロールイベントで計算し、コールバックに渡します。中身は CSS の `position: sticky` で画面に固定しつつ、この進捗値でシンボルの回転角度・表示するサービス項目・進捗バーの幅を連続的に変化させています。GSAP ScrollTriggerの `scrub` オプションと同じ考え方を、ネイティブAPIだけで再現したものです。

4. **`initTiltCards(cards, maxDeg)` — マグネティック・チルトカード**
   カード内でのマウス位置を中心からのズレ(-0.5〜0.5)に変換し、そのまま `rotateX` / `rotateY` に渡すことで、カーソルの位置に応じてカードがわずかに傾く「3Dっぽい」ホバー効果を作っています。カーソルが離れたら `transform` をリセットして平面に戻します。

5. **`initAmbientAudio(button)` — Web Audioによるアンビエントドローン**
   2つのオシレーター(サイン波)を完全5度に近い比率でわずかにデチューンして重ね合わせ、`BiquadFilterNode`(ローパスフィルター)を通しています。さらに0.08Hzという非常にゆっくりしたLFO(低周波オシレーター)でフィルターのカットオフ周波数を揺らすことで、「呼吸するような」アンビエントドローンを作っています。`AudioContext` はブラウザの自動再生ポリシーによりユーザー操作(クリック)が起点でないと生成・再開できないため、ボタンのクリックイベント内で初期化しています。

### つまずきやすいポイント(実装時に直面した問題と対策)

- **ネットワーク制限で実サイトを直接見られなかった**: このセッションの実行環境では `trionn.com`・`awwwards.com`・`cssdesignawards.com`・`wikipedia.org` など、調査に使いたかったサイトへの直接アクセスがすべてネットワークポリシーでブロックされていました(`EGRESS_BLOCKED`)。そのため検索結果に表示された要約文(受賞歴・使用技術・Codrops記事の紹介文)のみを根拠に設計しており、実サイトの正確なレイアウトや配色、細かいタイミングまでは確認できていません。このデモは「公開情報から読み取れる範囲での解釈による再現」であり、実サイトの完全な再現ではないことにご留意ください。
- **フラグメントシェーダー内でのマウス位置とアスペクト比の整合**: 霧のノイズ座標 `p` はアスペクト比補正後に2.6倍しているのに対し、発光(グロー)の距離計算をそのまま同じスケールで行うと座標系がずれてカーソルと発光位置が合わなくなりました。ノイズ用の座標系とグロー計算用の座標系(`uv`ベース、0〜1にアスペクト比だけ補正)を分けることで解決しています。
- **Lenisのような「仮想スクロール(スクロールバーを乗っ取ってtransformで滑らかに動かす)」の扱い**: 本物のLenisは、実際のスクロールイベントを間引いて `transform: translateY()` で描画位置をなめらかに追従させる「仮想スクロール」を行いますが、これをそのまま実装すると `position: sticky` によるピン留めが機能しなくなったり、キーボード操作・スクリーンリーダーでのアクセシビリティが壊れやすくなります。このデモでは安全性と学習のしやすさを優先し、ネイティブのスクロールはそのまま使いながら、シェーダーのマウス追従など「値のなめらかさ」が欲しい部分だけを線形補間(lerp)で近似する方針にしました。本格的なLenis風の仮想スクロールを追加したい場合は、この`initScrollScrub`をベースに、スクロール位置の目標値と現在値を毎フレームlerpして`translateY`に反映する層を上に重ねると近づけられます。

## 使い方(コピーしてすぐ使う手順)

1. `index.html` を1ファイルごと自分のプロジェクトにコピーします(外部ライブラリ・画像・フォントへの依存は一切ありません)。
2. そのままダブルクリックで `file://` として開いても動作します。ローカルサーバー経由で見る場合は以下のようにします。

   ```bash
   cd sites/2026-08-08-trionn-shader-fog-scroll
   python3 -m http.server 8080
   # ブラウザで http://localhost:8080 を開く
   ```

3. 霧の色味を変えたい場合は、フラグメントシェーダー内の `deep` / `mid` / `hot` の3色(`vec3`)を書き換えるだけで、グラデーション全体の配色が変わります。
4. 霧の流れる速さは `p.y -= uTime * 0.10;` の係数を、渦の強さは `warped = p + warp * 1.1;` の係数を変更すると調整できます。
5. スクラブセクションの項目数を増やしたい場合は、`#services-list` 内の `.item` を追加し、`initScrollScrub` 内の `items.length` を使った計算がそのまま自動で割り付けを再計算するため、JS側の変更は不要です。
6. マグネティックカードの傾き具合は `initTiltCards(document.querySelectorAll('.card'), 10)` の第2引数(最大角度)を変更するだけで調整できます。
7. アンビエントサウンドの音色は `initAmbientAudio()` 内の `oscA.frequency.value` / `oscB.frequency.value`(基音とその比率)や `lfo.frequency.value`(揺れの速さ)を変更すると変わります。
